# 库能力 spec

- 模块：err
- 对照：`netwib-src/src/netwib/err.h`（HTML 无独立 err 节）
- 状态：draft

## 能力

统一失败分类，供库与 CLI 展示。原数值分区：

| 区间 | 含义 |
|------|------|
| 0 | 成功 |
| 1000–1999 | 常见数据/路由类失败（如数据结束、不可用、路由找不到） |
| 2000–2999 | 参数错误（范围非法、hex/mixed/base64 非法、选项未按 4 字节对齐等） |
| 3000–3999 | 逻辑错误（未实现、对象未初始化） |
| 4000–9999 | 函数/系统错误 |
| ≥10000 | 用户自定义起点 |

工具 0 `--error` 要把码格式化为可读文本。默认**不**要求与 C 数值 1:1；若某工具输出依赖具体码，在该工具 spec 写明。

## Rust 形状

`nz-net` 内 `Error` + `Result`。用枚举表达分区与常见变体（数据结束、参数非法、未实现），`Display` 给人类可读串。禁止 `netwib_*` 符号。

## 非目标

- 不公开 C 错误码表作为稳定 ABI
- 不在本 spec 实现工具 0（见日后工具 0 spec）

## 验收

- [ ] `error_ok_is_success`：成功路径不是错误
- [ ] `error_kinds_display`：至少覆盖数据结束、参数非法、未实现三类，文本非空
- [ ] `error_user_range_reserved`：自定义错误可放在「用户」分区语义下，不与库变体冲突
