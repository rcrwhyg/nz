# 工具 spec

- 相位：11（remadm）

## 行为

TCP mulser 监听；供 94/95/96 执行命令、取文件、放文件。`--allow-exec/get/put` 均**默认开**；`--password` 缺省 `netwox`；`--timeout` **秒**缺省 60。

共用见 [_common.md](_common.md)。

## CLI

Usage：`nz 93 -P port [-w pass] [-c ips] [-r dir] [-T sec] [-X|+X] [-G|+G] [-U|+U]`
