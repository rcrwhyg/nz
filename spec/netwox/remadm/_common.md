# remadm 共用字段

对照 [doc/netwox/remadm.md](../../../doc/netwox/remadm.md)。

## 服务端（93）

| 长名 | 短 | 默认 | 含义 |
|------|-----|------|------|
| `--src-port` | `-P` | （必填语义） | 监听 |
| `--password` | `-w` | `netwox` | 弱口令 |
| `--allowed-clients` | `-c` | `all` | |
| `--rootdir` | `-r` | | 文件根 |
| `--timeout` | `-T` | **`60`**（秒） | 会话 |
| `--allow-exec` | `-X` | **开** | |
| `--allow-get` | `-G` | **开** | |
| `--allow-put` | `-U` | **开** | |

## 客户（94/95/96）

| 长名 | 短 | 默认 | 含义 |
|------|-----|------|------|
| `--dst-ip` | `-i` | （必填） | 服务器 |
| `--dst-port` | `-p` | （必填） | |
| `--password` | `-w` | `netwox` | |
| `--cypher` | `-x` | 关 | 弱加密开关 |
| `--timeout` | `-T` | **`100`**（秒） | |

94 额外：`--command`（`-c`）必填。
95 额外：`--file`（`-f`）远端文件名必填。
96 额外：`--src-file`（`-f`）本地必填 + `--dst-file`（`-F`）远端必填。
94/95 可选 `-F` 将结果写本地文件。

## 126 — HTTP 远程管理

| 长名 | 短 | 默认 | 含义 |
|------|-----|------|------|
| `--src-port` | `-P` | `80` | 监听 |
| `--login` | `-l` | | 可选 |
| `--password` | `-L` | | 可选 |
| `--timeout` | `-T` | `60000`（ms） | |
| `--allowed-clients` | `-c` | `all` | |

## 非目标

- 默认口令不当安全配置
- 仅实验室/书面授权
