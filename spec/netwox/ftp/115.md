# 工具 spec

- 工具号：115
- 标题：FTP client : get a directory recursively
- 建议名：`ftp-get-dir`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/115.html`
- 源：`src/netwox-src/src/tools/000115.c`
- 树节点：client TCP FTP
- 同义词：download
- 相位：10（FTP/TFTP 族）
- 状态：draft

## 行为

递归下载 `--remote-dir` 到 `--local-dir`。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 115 -i ip [-p port] [-u user] [-a pass] [-V|+V] -F remote-dir -f local-dir [-T ms]`

| `-i` | `--dst-ip` | ip（必填） | | FTP 服务器 |
| `-p` | `--dst-port` | port | `21` | 控制端口 |
| `-u` | `--user` | login | `anonymous` | |
| `-a` | `--pass` | password | `user@` | |
| `-V` | `--passive` | bool | 关 | PASV |
| `-T` | `--timeout` | uint32 | `60000` | ms |
| `-F` | `--remote-dir` | dir（必填） | | 远端 |
| `-f` | `--local-dir` | dir_wr（必填） | | 本地 |

## 例子

- `nz 115 --dst-ip 192.0.2.1 --remote-dir /pub --local-dir ./mirror`
