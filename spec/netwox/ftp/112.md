# 工具 spec

- 工具号：112
- 标题：FTP client : get a file
- 建议名：`ftp-get`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/112.html`
- 源：`src/netwox-src/src/tools/000112.c`
- 树节点：client TCP FTP
- 同义词：download
- 相位：10（FTP/TFTP 族）
- 状态：draft

## 行为

RETR 远端 `--remote-file` 到 `--local-file`。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 112 -i ip [-p port] [-u user] [-a pass] [-V|+V] -F remote -f local [-T ms]`

| `-i` | `--dst-ip` | ip（必填） | | FTP 服务器 |
| `-p` | `--dst-port` | port | `21` | 控制端口 |
| `-u` | `--user` | login | `anonymous` | |
| `-a` | `--pass` | password | `user@` | |
| `-V` | `--passive` | bool | 关 | PASV |
| `-T` | `--timeout` | uint32 | `60000` | ms |
| `-F` | `--remote-file` | file（必填） | `/etc/passwd` | 远端 |
| `-f` | `--local-file` | file_wr（必填） | `passwd_copy` | 本地 |

## 例子

- `nz 112 --dst-ip 192.0.2.1 --remote-file /pub/readme.txt --local-file readme.txt`
