# 工具 spec

- 工具号：113
- 标题：FTP client : put a file
- 建议名：`ftp-put`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/113.html`
- 源：`src/netwox-src/src/tools/000113.c`
- 树节点：client TCP FTP
- 同义词：upload
- 相位：10（FTP/TFTP 族）
- 状态：draft

## 行为

STOR 本地 `--local-file` 到远端 `--remote-file`。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 113 -i ip [-p port] [-u user] [-a pass] [-V|+V] -f local -F remote [-T ms]`

| `-i` | `--dst-ip` | ip（必填） | | FTP 服务器 |
| `-p` | `--dst-port` | port | `21` | 控制端口 |
| `-u` | `--user` | login | `anonymous` | |
| `-a` | `--pass` | password | `user@` | |
| `-V` | `--passive` | bool | 关 | PASV |
| `-T` | `--timeout` | uint32 | `60000` | ms |
| `-f` | `--local-file` | file_rd（必填） | | 本地 |
| `-F` | `--remote-file` | file（必填） | | 远端 |

## 例子

- `nz 113 --dst-ip 192.0.2.1 --local-file data.bin --remote-file upload/data.bin`
