# 工具 spec

- 工具号：166
- 标题：TFTP client : put a file
- 建议名：`tftp-put`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/166.html`
- 源：`src/netwox-src/src/tools/000166.c`
- 树节点：client UDP TFTP
- 同义词：upload
- 相位：10（FTP/TFTP 族）
- 状态：draft

## 行为

WRQ 上传 `--local-file` 到 `--remote-file`。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 166 -i ip [-p port] -f local -F remote [-m mode] [-T ms] [-R n]`

| `-i` | `--dst-ip` | ip（必填） | | TFTP 服务器 |
| `-p` | `--dst-port` | port | `69` | |
| `-m` | `--mode` | buf | `octet` | octet/netascii |
| `-T` | `--timeout` | uint32 | `10000` | ms |
| `-R` | `--retry` | uint32 | `3` | |
| `-f` | `--local-file` | file_wr（必填） | `passwd_copy` | |
| `-F` | `--remote-file` | file（必填） | `/etc/passwd` | |

## 例子

- `nz 166 --dst-ip 192.0.2.1 --local-file cfg --remote-file cfg`
