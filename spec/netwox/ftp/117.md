# 工具 spec

- 工具号：117
- 标题：FTP client : del a directory recursively
- 建议名：`ftp-rm-dir`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/117.html`
- 源：`src/netwox-src/src/tools/000117.c`
- 树节点：client TCP FTP
- 同义词：（无）
- 相位：10（FTP/TFTP 族）
- 状态：draft

## 行为

递归删除远端 `--remote-dir`。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 117 -i ip [-p port] [-u user] [-a pass] [-V|+V] -F remote-dir [-T ms]`

| `-i` | `--dst-ip` | ip（必填） | | FTP 服务器 |
| `-p` | `--dst-port` | port | `21` | 控制端口 |
| `-u` | `--user` | login | `anonymous` | |
| `-a` | `--pass` | password | `user@` | |
| `-V` | `--passive` | bool | 关 | PASV |
| `-T` | `--timeout` | uint32 | `60000` | ms |
| `-F` | `--remote-dir` | dir（必填） | | 待删远端目录 |

## 例子

- `nz 117 --dst-ip 192.0.2.1 --remote-dir /tmp/stale`（授权实验室）

## 权限 / 网络

仅授权实验室。
