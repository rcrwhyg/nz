# 工具 spec

- 工具号：176
- 标题：TFTP client : get a file and check its MD5
- 建议名：`tftp-get-md5`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/176.html`
- 源：`src/netwox-src/src/tools/000176.c`
- 树节点：client UDP TFTP
- 同义词：（无）
- 相位：10（FTP/TFTP 族）
- 状态：draft

## 行为

TFTP get 后比 `--md5`（`-s`）；`--timeout` 缺省 **60000**（非 10000）。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 176 -i ip [-p port] -F remote -s md5 [-m mode] [-T ms] [-R n]`

| `-i` | `--dst-ip` | ip（必填） | | TFTP 服务器 |
| `-p` | `--dst-port` | port | `69` | |
| `-m` | `--mode` | buf | `octet` | octet/netascii |
| `-T` | `--timeout` | uint32 | `60000` | ms |
| `-R` | `--retry` | uint32 | `3` | |
| `-F` | `--remote-file` | file（必填） | `/etc/passwd` | |
| `-s` | `--md5` | md5（必填） | | |

## 例子

- `nz 176 --dst-ip 192.0.2.1 --remote-file f --md5 abc...`
