# 工具 spec

- 工具号：174
- 标题：FTP client : get a file and check its MD5
- 建议名：`ftp-get-md5`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/174.html`
- 源：`src/netwox-src/src/tools/000174.c`
- 树节点：client TCP FTP
- 同义词：（无）
- 相位：10（FTP/TFTP 族）
- 状态：draft

## 行为

RETR 到临时文件并比 `--md5`（`-m`）；不匹配 `BADVALUE`。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 174 -i ip [-p port] [-u user] [-a pass] [-V|+V] -F remote -m md5 [-T ms]`

| `-i` | `--dst-ip` | ip（必填） | | FTP 服务器 |
| `-p` | `--dst-port` | port | `21` | 控制端口 |
| `-u` | `--user` | login | `anonymous` | |
| `-a` | `--pass` | password | `user@` | |
| `-V` | `--passive` | bool | 关 | PASV |
| `-T` | `--timeout` | uint32 | `60000` | ms |
| `-F` | `--remote-file` | file（必填） | `/etc/passwd` | 远端 |
| `-m` | `--md5` | md5（必填） | | 期望摘要 |

## 例子

- `nz 174 --dst-ip 192.0.2.1 --remote-file /pub/f --md5 d41d8cd98f00b204e9800998ecf8427e`
