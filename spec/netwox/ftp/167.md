## 行为

TFTP UDP mulser；`--allow-get`/`--allow-put` **默认开**。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 167 [-d device] [-E eth] [-I ip] -P port [-r rootdir] [-c ips] [-G|+G] [-U|+U] [-T ms] [-R n]`

| `-P` | `--src-port` | port | `69` | 监听 |
| `-r` | `--rootdir` | dir_rd | | 根 |
| `-c` | `--allowed-clients` | ips | `all` | |
| `-G` | `--allow-get` | bool | **开** | |
| `-U` | `--allow-put` | bool | **开** | |
| `-T` | `--timeout` | uint32 | `10000` | ms |
| `-R` | `--retry` | uint32 | `3` | |

## 例子
