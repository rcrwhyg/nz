# 工具 spec

- 工具号：165
- 标题：TFTP client : get a file
- 建议名：`tftp-get`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/165.html`
- 源：`src/netwox-src/src/tools/000165.c`
- 树节点：client UDP TFTP
- 同义词：download
- 相位：10（FTP/TFTP 族）
- 状态：draft

## 行为

RRQ 下载 `--remote-file` 到 `--local-file`。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 165 -i ip [-p port] -F remote -f local [-m mode] [-T ms] [-R n]`

| `-i` | `--dst-ip` | ip（必填） | | TFTP 服务器 |
| `-p` | `--dst-port` | port | `69` | |
| `-m` | `--mode` | buf | `octet` | octet/netascii |
| `-T` | `--timeout` | uint32 | `10000` | ms |
| `-R` | `--retry` | uint32 | `3` | |
| `-F` | `--remote-file` | file（必填） | `/etc/passwd` | |
| `-f` | `--local-file` | file_wr（必填） | `passwd_copy` | |

## 例子

- `nz 165 --dst-ip 192.0.2.1 --remote-file boot.bin --local-file boot.bin`

## 权限 / 网络

无特权。CI 假 TFTP。
