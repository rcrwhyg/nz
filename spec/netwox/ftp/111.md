# 工具 spec

- 工具号：111
- 标题：FTP listing a directory
- 建议名：`ftp-ls`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/111.html`
- 源：`src/netwox-src/src/tools/000111.c`
- 树节点：client TCP FTP
- 同义词：（无）
- 相位：10（FTP/TFTP 族）
- 状态：draft

## 行为

LIST 远端 `--dir` 并打印目录列表。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 111 -i ip [-p port] [-u user] [-a pass] [-V|+V] -D dir [-T ms]`

| `-i` | `--dst-ip` | ip（必填） | | FTP 服务器 |
| `-p` | `--dst-port` | port | `21` | 控制端口 |
| `-u` | `--user` | login | `anonymous` | |
| `-a` | `--pass` | password | `user@` | |
| `-V` | `--passive` | bool | 关 | PASV |
| `-T` | `--timeout` | uint32 | `60000` | ms |
| `-D` | `--dir` | dir（必填） | `/etc/` | 远端目录 |

## 例子

- `nz 111 --dst-ip 192.0.2.1 --dir /pub`

## 权限 / 网络

无特权。CI 假 FTP。
