# 工具 spec

- 工具号：168
- 标题：FTP server
- 建议名：`ftp-server`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/168.html`
- 源：`src/netwox-src/src/tools/000168.c`
- 树节点：server TCP FTP
- 同义词：proftpd, wuftpd
- 相位：10（FTP/TFTP 族）
- 状态：draft

## 行为

FTP 多客户服务；静态/可写由 `--allow-put` 控制（**默认开**）。`--timeout` **180000 ms**。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 168 [-d device] [-E eth] [-I ip] -P port [-r rootdir] [-l login] [-L password] [-T ms] [-c ips] [-U|+U]`

| `-P` | `--src-port` | port | `21` | 监听 |
| `-r` | `--rootdir` | dir_rd | | 根目录 |
| `-l` | `--login` | login | | |
| `-L` | `--password` | password | | |
| `-T` | `--timeout` | uint32 | **`180000`** | ms |
| `-c` | `--allowed-clients` | ips | `all` | |
| `-U` | `--allow-put` | bool | **开** | 允许 STOR 等 |

## 例子

- `nz 168 --src-port 2121 --rootdir ./ftp-root`

## 权限 / 网络

绑定 21 可能需特权。CI 假 mulser。
