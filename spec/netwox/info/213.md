# 工具 spec

- 工具号：213
- 标题：Display a list of IP addresses
- 建议名：`ip-list`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/213.html`
- 源：`src/netwox-src/src/tools/000213.c`
- 树节点：not-network
- 相位：3
- 状态：draft

## 行为

展开 IP 集合（排序且去重，`IPS_SU`），供其它工具当输入。无 `--separator`：每地址一行（含换行）。有 separator：拼成一行，项之间插入该串，**末尾不再为每项加换行**。

另见日后工具 24（网段换算）。`--separator` 为 Advanced。

## CLI

Usage：`nz 213 -i ips [-s data]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--ips` | ips（必填） | （无；HTML 示例 `all`） | 要展开的集合 |
| `-s` | `--separator` | data | 未设置 | 连接串 |

## 例子

- `nz 213 --ips 1.2.3.4-1.2.3.6 --separator ","` → `1.2.3.4,1.2.3.5,1.2.3.6`
- `nz 213 -i 1.2.3.4-1.2.3.5` → 两行

## 权限 / 网络

无。不解析主机名也可验收纯数字范围。
