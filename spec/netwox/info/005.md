# 工具 spec

- 工具号：5
- 标题：Obtain Ethernet addresses of computers in an IP list
- 建议名：`arp-scan`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/5.html`
- 源：`src/netwox-src/src/tools/000005.c`
- 树节点：information on remote computer
- 同义词：host, mac, resolve, show
- 相位：3
- 状态：draft

## 行为

对 IP 列表/网段逐个解析 Ethernet：IPv4 用 ARP，IPv6 用 Neighbor Discovery。成功一行：`ip`、制表符、`eth`。

`--unresolved` **默认关**（C `OPT_BOOL` 空默认 = false）。开则未解析打印 `ip\tunresolved`；关则跳过未解析项。HTML 正文写「`--no-unresolved` 才隐藏」与 C/参数表不一致，**以 C 为准**。

`--ips` 为必填，类型为不排序且去重（`IPS_U`）。表单缺省示例 `192.168.1.0/24`。

## CLI

Usage：`nz 5 [-u|+u] -i ips`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--ips` | ips（必填） | 示例 `192.168.1.0/24` | 列表/范围 |
| `-u` | `--unresolved` | bool | 关 | 打印未解析项 |

## 例子

- `nz 5 -i 127.0.0.1`（假 ARP）
- 文档例 `192.168.1.0/24` 仅实验室/授权目标

## 权限 / 网络

需 sniff/spoof 才能真解析。仅本机/实验室/书面授权目标。CI 假接口，不对公网。
