# 工具 spec

- 工具号：3
- 标题：Display information about an IP address or a hostname
- 建议名：`host-info`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/3.html`
- 源：`src/netwox-src/src/tools/000003.c`
- 树节点：information on remote computer
- 同义词：ethernet, ip4, ip6, mac, resolve, show
- 相位：3
- 状态：implemented

## 行为

由 IP 或主机名查出 IP、主主机名、全部主机名、Ethernet。查不到的项打印 `unresolved`。

显示类开关（含 `--title`）**全部关**时：标题与 ip/host/hosts/eth **全开**（以 C 为准；HTML 漏写了 title 也参与「全关」判断）。只开其中一部分则只打那些。

`--all`：把 `--query` 当 IP 集合展开，逐地址显示（地址之间空行）。未开 `--all` 时只解析**第一个**地址。

Ethernet 解析可能 sniff/spoof。GUI Remote_info 走本工具。

实现默认 [`FakeHostResolver`]（回环 + 假 ARP）；不对公网。

## CLI

Usage：`nz 3 -q hostname [-t|+t] [-i|+i] [-h|+h] [-H|+H] [-e|+e] [-a|+a]`

除 `--query` 外均为 Advanced。

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-q` | `--query` | hostname/IP（必填） | （无） | 查询目标 |
| `-t` | `--title` | bool | 关* | 每行加标题 |
| `-i` | `--ip` | bool | 关* | IP |
| `-h` | `--host` | bool | 关* | 主主机名 |
| `-H` | `--hosts` | bool | 关* | 全部主机名 |
| `-e` | `--eth` | bool | 关* | Ethernet |
| `-a` | `--all` | bool | 关 | 展开列表/网段 |

\* 五者全关则五者全开。

## 例子

- `nz 3 -q 127.0.0.1`（自动化用回环/假解析，不用公网主机名）
- 文档例 `www.example.com` 不作 CI

## 权限 / 网络

`--eth` 可能需 sniff/spoof。禁止对未授权公网做集成测试。假 DNS / 假 ARP。

- [x] `t003_unresolved_literal`：假解析失败时出现 `unresolved`
