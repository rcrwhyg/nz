## 行为

列出难猜参数类型的合法取值，供 CLI 查阅。GUI 用控件枚举，不必依赖本工具输出排版。

至少包含（对照 `toolarg.c` 帮助）：

| 类型 | 取值（可映射，允许增别名） |
|------|---------------------------|
| encode | data, hexa, mixed, text, base64, nothing, synth, data_wrap, hexa_wrap, mixed_wrap, text_wrap, base64_wrap, array, dump, lowercase, uppercase, mixedh_wrap |
| recordencode | hexa, mixed, hexa_wrap, mixed_wrap, dump, mixedh_wrap, bin, pcap |
| decode | data, hexa, mixed, base64 |
| dlt | null, ether, raw, …（全表与 `device.h` DLT 枚举对应） |
| spoofip | raw, linkf, linkb, linkfb, rawlinkf, rawlinkb, rawlinkfb, linkfraw, linkbraw, linkfbraw, link, rawlink, linkraw, best |
| iptype | ip4, ip6 |

另可列出 ip/eth/port/ips 等形态示例。`recordencode` 必须含 `mixedh_wrap`（HTML 工具 16 曾漏）。
