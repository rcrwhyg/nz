# 工具 spec

- 工具号：6
- 标题：Display how to reach an IP address
- 建议名：`route-to`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/6.html`
- 源：`src/netwox-src/src/tools/000006.c`
- 树节点：information on remote computer
- 同义词：device, gateway, ip4, ip6, mac, router
- 相位：3
- 状态：draft

## 行为

给出到达某 IP 的：网卡、源 IP、目的 IP、源 Ethernet、目的 Ethernet（跨网段时为网关 MAC）。缺字段打印 `unresolved`。目的 IP 在请求里已有，故「目的 IP」只要开关开着总能显示。

显示开关（含 `--title`）全关则全开。解析 Eth 可能需权限。

## CLI

Usage：`nz 6 [-t|+t] [-d|+d] [-i|+i] [-I|+I] [-e|+e] [-E|+E] -q ip`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-q` | `--ip` | ip（必填） | （无） | 目的；C 未写长名，按类型为 `ip` |
| `-t` | `--title` | bool | 关* | 标题 |
| `-d` | `--device` | bool | 关* | 网卡 |
| `-i` | `--src-ip` | bool | 关* | 源 IP |
| `-I` | `--dst-ip` | bool | 关* | 目的 IP |
| `-e` | `--src-eth` | bool | 关* | 源 Eth |
| `-E` | `--dst-eth` | bool | 关* | 目的 Eth |

\* 六者全关则六者全开。

## 例子

- `nz 6 -q 127.0.0.1`（假路由）
- 文档例 `192.168.100.200` 不作 CI 真网

## 权限 / 网络

Eth 解析可能需 sniff/spoof。假路由表。不对公网。
