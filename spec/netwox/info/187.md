# 工具 spec

- 工具号：187
- 标题：Display date and time
- 建议名：`datetime`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/187.html`
- 源：`src/netwox-src/src/tools/000187.c`
- 树节点：not-network
- 相位：3
- 状态：draft

## 行为

显示 `--time`（Unix 秒）或当前时间。五种格式是 **radio1 互斥**：一次只打一种。默认 `--disp-rfc822`（`RADIO1_SET`）。

| 键 | 格式 |
|----|------|
| `-r` | RFC 822 |
| `-u` | unix `date(1)` 风格 |
| `-h` | 人类可读 |
| `-s` | 秒 |
| `-n` | 秒 + 纳秒 |

`--time` 未给则用现在；给出则 `nsec=0`。输出末尾换行。

## CLI

Usage：`nz 187 [-t uint32] [-r|+r] [-u|+u] [-h|+h] [-s|+s] [-n|+n]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-t` | `--time` | u32 | 现在 | Unix 秒 |
| `-r` | `--disp-rfc822` | radio1 | **开** | RFC 822 |
| `-u` | `--disp-unixdate` | radio1 | 关 | date(1) |
| `-h` | `--disp-human` | radio1 | 关 | 人类可读 |
| `-s` | `--disp-sec` | radio1 | 关 | 秒 |
| `-n` | `--disp-secnsec` | radio1 | 关 | 秒+纳秒 |

## 例子

- `nz 187`
- `nz 187 -t 0 -s` → 秒为 `0`

## 权限 / 网络

无。测试钉死 `--time`，不要依赖墙钟。

## 验收

- [ ] `t187_help_parses`
- [ ] `t187_default_rfc822_at_epoch`：`-t 0` 输出可解析为 RFC 822 且表示 1970-01-01 UTC 附近
- [ ] `t187_sec_is_zero`：`-t 0 -s` 为 `0`
- [ ] `t187_radio_exclusive`：`-s` 时输出为秒格式，不是 RFC 822（radio1 互斥，默认 rfc822）
