# 工具 spec

- 工具号：13
- 标题：Obtain DLT type for sniff and spoof for each device
- 建议名：`dlt-info`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/13.html`
- 源：`src/netwox-src/src/tools/000013.c`
- 树节点：sniff；spoof Ethernet；spoof IP
- 同义词：capture, device
- 相位：3
- 状态：draft

## 行为

报告：

1. 本机是否支持 raw IPv4 spoof、raw IPv6 spoof（支持时应为 DLT `raw`）
2. 每块网卡：硬件类型；sniff 是否可用及其 DLT；spoof（链路）是否可用及其 DLT

打开通道失败且原因为「不支持」时打印 not supported，其它错误打印错误文本。CI 用假网卡/假通道，不真正打开 pcap。

## CLI

Usage：`nz 13`

无参数。

## 例子

- `nz 13`

## 权限 / 网络

探测 sniff/spoof 可能需权限。不对公网发包。假后端即可验收。
