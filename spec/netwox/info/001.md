## 行为

打印本机四块配置。无显示类开关（或全关）则四块都打；给出任一开着的开关则只打那些块。

| 块 | 字段 |
|----|------|
| devices | 编号、易记名、Eth 或硬件类型、MTU、真实设备名 |
| ip | 网卡编号、IP、掩码、是否 PPP、PPP 对端 |
| arpcache | 网卡编号、Eth、IP（含 IPv6 neighbor） |
| routes | 网卡编号、目的/掩码、源或 `local`、网关、metric |

GUI Local_info 字段对齐本工具；启动数据走工具 0 `--conf`，不强制再跑本工具。排版可现代化。

## CLI

Usage：`nz 1 [-d|+d] [-i|+i] [-a|+a] [-r|+r]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-d` | `--devices` | bool | 关 | 网卡 |
| `-i` | `--ip` | bool | 关 | 地址 |
| `-a` | `--arpcache` | bool | 关 | ARP / neighbor |
| `-r` | `--routes` | bool | 关 | 路由 |

## 例子

- `nz 1`：四块都出现
- `nz 1 -d`：只有 devices
