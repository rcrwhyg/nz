# 工具 spec

- 工具号：2
- 标题：Display debugging information
- 建议名：`debug-info`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/2.html`
- 源：`src/netwox-src/src/tools/000002.c`
- 树节点：information on netw
- 相位：3
- 状态：implemented

## 行为

打印排障信息：程序/库版本、编译或目标平台相关定义、本机配置如何取得。报 bug 时附上。不要求与 C `#define` 清单 1:1，但须有版本三元组与「conf 来源」两类可测块，并以明确结束标记收尾（原输出最后一行为 `END`）。

实现：`conf_source=system-inventory` 或失败时 `fake-sample`；并转储四表摘要。

## CLI

Usage：`nz 2`

无参数。

## 例子

- `nz 2`

## 权限 / 网络

读 conf 可能需权限。CI 可用真系统或假 conf。
