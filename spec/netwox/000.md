## 行为

非交互用户工具。GUI 用它拉目录、帮助、表单回填、运行、杀进程、本机配置和版本。

无开关：成功且无信息面输出。多个开关可同时开，执行顺序：
tools → toolhelp → formupdate → run → run-key → kill → error → conf → version。

## CLI

Usage：`nz 0 [switches…]`

| 短 | 长 | 类型 | 默认 | 含义 | 切片 |
|----|----|------|------|------|------|
| `-t` | `--tools` | bool | 关 | 工具目录 | **1** |
| `-h` | `--toolhelp` | bool | 关 | help/example/usage/form | **2** |
| `-f` | `--formupdate` | bool | 关 | 命令行→表单；读完删文件 | **2** |
| `-r` | `--run` | bool | 关 | 读文件当 argv 执行；读完删 | **3** |
| `-R` | `--run-key` | bool | 关 | 同 run，再等按键 | **3** |
| `-k` | `--kill` | bool | 关 | 杀 PID；已死忽略 | **3** |
| `-e` | `--error` | bool | 关 | 错误码可读文本 | **1** |
| `-c` | `--conf` | bool | 关 | 本机配置四表 | **3** |
| `-v` | `--version` | bool | 关 | 版本三元组 | **1** |
| `-b` | `--buf` | string | 空 | 路径或 kill 毫秒 | **2–3** |
| `-u` | `--uint` | u32 | 0 | 工具号/PID/错误码 | **1–3** |

### 行协议摘要

- `section:tools` / `toolhelp` / `formupdate` / `run` / `kill` / `error` / `conf` / `version`
- `--run` 的 `child_output` 可内嵌子工具（如 `0 -v`）的 section
- `--conf`：`device:` / `ip:` / `arp:` / `route:` 行
