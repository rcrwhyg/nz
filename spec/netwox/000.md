## 行为

非交互用户工具。GUI 用它拉目录、帮助、表单回填、运行、杀进程、本机配置和版本。

`nz 0` 必须提供同等契约（短/长名可映射）。原输出是 Tcl 片段；egui **不要求 Tcl**，每个开关的信息面必须可测（结构化值或稳定文本）。

无开关：成功且无信息面输出。多个开关可同时开，按下列顺序执行：tools → toolhelp → formupdate → run → run-key → kill → error → conf → version。

## CLI

Usage：`nz 0 [switches…]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-t` | `--tools` | bool | 关 | 工具目录：排序表、同义词、分类树、stdin/backspace |
| `-h` | `--toolhelp` | bool | 关 | 指定工具的 help / example / usage / form；工具号见 `-u` |
| `-f` | `--formupdate` | bool | 关 | 命令行 → 表单回填；`-u` 工具号，`-b` 命令文件 |
| `-r` | `--run` | bool | 关 | 读 `-b` 当 `nz` argv 并执行 |
| `-R` | `--run-key` | bool | 关 | 同 `--run`，结束后等按键 |
| `-k` | `--kill` | bool | 关 | 结束进程：`-u` 为 PID，`-b` 为杀掉前睡眠的毫秒数 |
| `-e` | `--error` | bool | 关 | 把 `-u` 当作错误码，打印可读文本 |
| `-c` | `--conf` | bool | 关 | 本机 devices / IP / ARP 或 neighbor / routes（GUI Local_info） |
| `-v` | `--version` | bool | 关 | 版本三元组（`nz` crate，不是 5.39.0） |
| `-b` | `--buf` | string | 空 | 命令文件路径，或 kill 的毫秒数字符串 |
| `-u` | `--uint` | u32 | 0 | 工具号、PID 或错误码 |

布尔为 `-x|+x|--no-x`。

### `--tools` 信息面

- 已发布工具的最大号与条数
- 排序表：每条 `号` + 标题（从 1 起，不含 0、218、默认不含后置）
- 同义词：每条工具的小写搜索词（无则空）
- 分类树：节点标签 + 子节点（分类或工具号）；对照 `tooltree.c`，不要求 C 的 `toolstart=1000`
- 需要 stdin：7、14、87、88、89、90、99、152、171
- 需要 backspace：138、139、210

### `--toolhelp` 信息面

对 `-u` 指定的已登记工具：

- help：号 + 说明正文
- example：示例命令行
- usage：usage 行
- form：普通参数，若有则另附 Advanced 分组

每参数可映射：短选项、长名、类型、默认、是否 advanced、是否必填。未知工具号失败。

### 命令文件（`--formupdate` / `--run` / `--run-key`）

文件内容是用户在 Run 行输入的那种命令：首 token 为工具号，后接该工具参数。例：`49 -i 1.2.3.4`。

读法对照 `conffile_read_concat`：去掉空行与 `#` 注释行，其余行用空格拼接。成功**读到**文件后**删除该文件**（即使随后解析失败）。读文件失败则不删。

`formupdate`：跳过文件里的工具号（与 argv[0] 一样），按 `-u` 的工具解析其余参数；只回填**用户显式给出**的项（短选项字母 + 值）。多余位置参数用假键 `-` 一条串起来。解析失败：非零退出；原版抑制错误展示，nz 可用简短文本，GUI 当警告。

`run`：把拼接结果当成 `nz` 的 argv（含工具号）执行，返回被调工具的退出语义。

`run-key`：先 `run`，再等待任意键（测试注入按键，不要真阻塞 CI）。

### `--kill`

先按 `-b` 睡眠若干毫秒（GUI 常用 `500`），再向 `-u` PID 发终止。目标已不存在：**忽略，当作成功**。

### `--error`

把 `-u` 格式化为可读文本（见 [err.md](../netwib/err.md)）。不要求与 C 数值 1:1。

### `--conf`

四块，字段对齐工具 1：devices、ip、arp/neighbor、routes。启动 Local_info 走本开关，不直接跑工具 1。真网卡在 CI 不可用时用假数据。完整实现依赖日后 `net-conf` spec。

### `--version`

三个非负整数：major、minor、micro。来自 `nz` 包版本。

## 例子

- `nz 0 --tools`：目录可被 Search 消费
- `nz 0 -h -u 1`：工具 1 的 help/example/usage/form
- `nz 0 -f -b FILE -u 1`：FILE 含 `1 -d` 一类，回填 `-d`，然后 FILE 不存在
- `nz 0 -v`：三个版本数字

## 权限 / 网络

本工具自身无特权。`--conf` 读本机配置可能需权限；`--run` 跟随被调工具。不对公网做集成测试。
