## 行为

非交互用户工具。GUI 用它拉目录、帮助、表单回填、运行、杀进程、本机配置和版本。

无开关：成功且无信息面输出。多个开关可同时开，执行顺序：
tools → toolhelp → formupdate → run → run-key → kill → error → conf → version。

### 行协议（切片 1）

信息面为 UTF-8 文本，分段以 `section:<name>` 起头；字段 `key:value`（值内不含换行）。测试优先消费结构化 API，CLI 打印同一协议。

#### `--tools` → `section:tools`

- `max_id` / `count`：已发布（Release）工具
- `tool:<id>:<title>:<suggested_name>`（按号排序，从 1 起；不含 0、218、后置）
- `synonym:<id>:<token>`（标题拆词小写；可多行）
- `stdin:<id>` / `backspace:<id>`
- `tree_node:<name>` / `tree_child_tool:<parent>:<id>` —— 切片 1 仅 `main` 下挂全部 Release 工具；完整 `tooltree` 映射后置

#### `--version` → `section:version`

- `major` / `minor` / `micro`：来自 `nz` 包版本（非 5.39.0）

#### `--error` → `section:error`

- `code`：`-u` 的值
- `text`：可读说明（不要求与 C 数值 1:1；见 [err.md](../netwib/err.md)）
