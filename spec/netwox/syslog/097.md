## 行为

向 `--dst-ip` 发一条 syslog UDP 报文（端口 **514**）。`--priority` 缺省 **0**；`--message` 缺省 `hello`。

## CLI

Usage：`nz 97 -i ip [-p 514] [-y priority] [-m message]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--dst-ip` | ip（必填） | | 服务器 |
| `-p` | `--dst-port` | port | `514` | |
| `-y` | `--priority` | uint32 | `0` | RFC 优先级 |
| `-m` | `--message` | buf | `hello` | 消息 |

## 例子

- `nz 97 --dst-ip 192.0.2.1 --message "test alert"`

## 权限 / 网络
