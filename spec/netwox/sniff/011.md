# 工具 spec

- 工具号：11
- 标题：Sniff and verify checksums
- 建议名：`sniff-csum`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/11.html`
- 源：`src/netwox-src/src/tools/000011.c`、`modules/checksum.c`
- 树节点：sniff
- 同义词：capture
- 相位：6
- 状态：draft

## 行为

校验 IP/TCP/UDP/ICMP 等校验和。坏的连同期望值显示（形态可现代化，须能区分 ok 与 `见到!=期望`）。解不出 IP/UDP/TCP 时打 not decoded 一类并继续。`--rawip`、`--ipreas` 语义同工具 7（Advanced，默认关）。分片当未知载荷，不强制验传输层。需 sniff 权限。

## CLI

Usage：`nz 11 [-d device] [-f filter] [-r|+r] [-i|+i]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-d` | `--device` | device | （缺省网卡） | 网卡 |
| `-f` | `--filter` | filter | （空） | BPF/pcap |
| `-r` | `--rawip` | bool（Advanced） | 关 | 从 IP 头起 |
| `-i` | `--ipreas` | bool（Advanced） | 关 | IP 重组 |
