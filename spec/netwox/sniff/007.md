## 行为

抓包：打到屏幕和/或写入 record。需 sniff 权限。工具 0 标 stdin（`--pause`）。

`--pause`：`P`/`p` **只切换屏幕**（落盘不停）；`Q`/`q` 退出；其它键提示再按。`--screen` 与 `--extended` **默认开**。`--ipreas` / `--tcpreord` 默认关，允许丢包；`--tcpreord` 时 C 会先挂 IP 重组再挂 TCP 重排。`--rawip` 忽略链路，record DLT 为 `raw`，否则为工具 13 的 sniff DLT。

未给 `--outfile` 则不落盘。`--split-size` 或 `--split-age` 非 0 时，文件名为 `basename.YYYYMMDD_HHMMSS.N`（N 从 1）。HTML 写 split-size 单位为 kb；**C 把该整数直接与累计包字节比较**（不乘 1024），以 C 为准。超限后**先换文件再写触发包**。Linux `--losepriv`（`-Q`）在打开通道之后降到 nobody，默认关。

## CLI

Usage：`nz 7 [-d device] [-f filter] [-p|+p] [-H encode] [-D encode] [-r|+r] [-x|+x] [-i|+i] [-t|+t] [-s|+s] [-o file] [-R recordencode] [-c uint32] [-C uint32] [-Q|+Q]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-d` | `--device` | device | （缺省网卡） | 网卡 |
| `-f` | `--filter` | filter | （空） | BPF/pcap |
| `-p` | `--pause` | bool | 关 | 可暂停 |
| `-H` | `--hdrencode` | encode | `array` | 头展示 |
| `-D` | `--dataencode` | encode | `dump` | 载荷展示 |
| `-r` | `--rawip` | bool（Advanced） | 关 | 从 IP 头起 |
| `-x` | `--extended` | bool（Advanced） | **开** | 解其它协议 |
| `-i` | `--ipreas` | bool（Advanced） | 关 | IP 重组 |
| `-t` | `--tcpreord` | bool（Advanced） | 关 | TCP 重排 |
| `-s` | `--screen` | bool（Advanced） | **开** | 打到屏幕 |
| `-o` | `--outfile` | 可写文件（Advanced） | （不落盘） | record |
| `-R` | `--recordencode` | recordencode（Advanced） | `bin` | 落盘编码 |
| `-c` | `--split-size` | uint32（Advanced） | `0` | 切文件阈值（C：字节） |
| `-C` | `--split-age` | uint32（Advanced） | `0` | 最长秒；`0` 不按时间切 |
| `-Q` | `--losepriv` | bool（Advanced） | 关 | Linux 降 nobody |

## 例子

- `nz 7`
- `nz 7 -o cap.bin -c 100`
