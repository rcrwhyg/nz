## 行为

连接 TCP 服务端，stdin 与套接字双向转发（类 telnet）。`--dst-ip` / `--dst-port` 必填。registry **stdin**。

共用 decode/encode 见 [_common.md](_common.md)。

## CLI

Usage：`nz 87 [-d device] [-E eth] [-e eth] [-I ip] -i ip [-P port] -p port [-o mixed] [-O mixed] [-k decode] [-n encode]`

| `-d` | `--device` | device | （缺省网卡） | 网卡 |
| `-E` | `--src-eth` | eth | HTML 示例 | 源 MAC；触发 VIRT |
| `-e` | `--dst-eth` | eth | | 目的 MAC |
| `-I` | `--src-ip` | ip | | 源 IP |
| `-i` | `--dst-ip` | ip（必填） | | 目的 IP |
| `-P` | `--src-port` | port | `0` | 源端口；0=系统分配 |
| `-p` | `--dst-port` | port（必填） | | 目的端口 |
| `-o` | `--ip4opts` | mixed | | IPv4 options |
| `-O` | `--ip6exts` | mixed | | IPv6 扩展 |
| `-k` | `--decode` | decode | `data` | 键盘输入编码 |
| `-n` | `--encode` | encode | `data` | 网络数据显示 |

## 例子

- `nz 87 --dst-ip 192.0.2.1 --dst-port 80`（文档地址，勿对公网）

## 权限 / 网络

无特权（REAL 路径）。VIRT 需 sniff+spoof。仅本机 / 实验室 / 书面授权。CI 假套接字。
