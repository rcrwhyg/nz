## 行为

监听 TCP，`--src-port` 必填；接受单客户后 stdin 与套接字双向转发。配 87 使用。registry **stdin**。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 89 [-d device] [-E eth] [-I ip] -P port [-o mixed] [-O mixed] [-t iptype] [-k decode] [-n encode]`

| `-d` | `--device` | device | （缺省网卡） | 网卡 |
| `-E` | `--src-eth` | eth | HTML 示例 | 源 MAC；触发 VIRT |
| `-I` | `--src-ip` | ip | | 源 IP |
| `-P` | `--src-port` | port（必填） | | 监听端口 |
| `-o` | `--ip4opts` | mixed | | IPv4 options |
| `-O` | `--ip6exts` | mixed | | IPv6 扩展 |
| `-t` | `--iptype` | iptype | `ip4` | 未给 `--src-ip` 时用 |
| `-k` | `--decode` | decode | `data` | 键盘输入编码 |
| `-n` | `--encode` | encode | `data` | 网络数据显示 |

## 例子

- `nz 89 --src-port 8080`

## 权限 / 网络

无特权（REAL 路径）。VIRT 需 sniff+spoof。CI 假套接字。
