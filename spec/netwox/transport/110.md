## 行为

双网卡以太网桥，可限速模拟慢链路。`--device1` / `--device2` 必填。学习 MAC、按 `--max12`/`--max21` 限速转发。`--verbose` **默认开**。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 110 -d device -D device [-m uint32] [-M uint32] [-v|+v]`

| `-d` | `--device1` | device（必填） | | 网卡 1 |
| `-D` | `--device2` | device（必填） | | 网卡 2 |
| `-m` | `--max12` | uint32 | `0` | 1→2 字节/秒；0=不限 |
| `-M` | `--max21` | uint32 | `0` | 2→1 字节/秒；0=不限 |
| `-v` | `--verbose` | bool | **开** | SNIFF/SPOOF 行 |

## 例子

- `nz 110 --device1 eth0 --device2 eth1 --max12 10000`（实验室双网卡）

## 权限 / 网络

需 sniff+spoof。CI 假双通道，不对真网卡 bridge。
