## 行为

TCP 多客户监听；每连接 `io_showecho`。`--src-port` 必填。`--echoback` **默认开**；`--showscreen` 默认关。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 91 [-d device] [-E eth] [-I ip] -P port [-o mixed] [-O mixed] [-t iptype] [-s|+s] [-b|+b]`

| `-d` | `--device` | device | （缺省网卡） | 网卡 |
| `-E` | `--src-eth` | eth | HTML 示例 | 源 MAC；触发 VIRT |
| `-I` | `--src-ip` | ip | | 源 IP |
| `-P` | `--src-port` | port（必填） | | 监听端口 |
| `-o` | `--ip4opts` | mixed | | IPv4 options |
| `-O` | `--ip6exts` | mixed | | IPv6 扩展 |
| `-t` | `--iptype` | iptype | `ip4` | 未给 `--src-ip` 时用 |
| `-s` | `--showscreen` | bool | 关 | 数据打到屏幕 |
| `-b` | `--echoback` | bool | **开** | 回显给客户 |

## 例子

- `nz 91 --src-port 8080`

## 权限 / 网络

无特权（REAL 路径）。CI 假多连接。
