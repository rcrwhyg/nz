## CLI

Usage：`nz 158 [-d device] [-E eth] [-e eth] [-I ip] -i ip [-P port] -p port [-o mixed] [-O mixed] [-s uint32] [-u uint32]`

| `-d` | `--device` | device | （缺省网卡） | 网卡 |
| `-E` | `--src-eth` | eth | HTML 示例 | 源 MAC；触发 VIRT |
| `-e` | `--dst-eth` | eth | | 目的 MAC |
| `-I` | `--src-ip` | ip | | 源 IP |
| `-i` | `--dst-ip` | ip（必填） | | 目的 IP |
| `-P` | `--src-port` | port | `0` | 源端口；0=系统分配 |
| `-p` | `--dst-port` | port（必填） | | 目的端口 |
| `-o` | `--ip4opts` | mixed | | IPv4 options |
| `-O` | `--ip6exts` | mixed | | IPv6 扩展 |
| `-s` | `--chunksize` | uint32 | `500` | DATA 块大小 |
| `-u` | `--duration` | uint32 | `5000` | 测试时长（ms） |

## 例子

- `nz 158 --dst-ip 192.0.2.1 --dst-port 5001 --duration 100`
