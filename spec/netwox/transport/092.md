## CLI

Usage：`nz 92 [-d device] [-E eth] [-I ip] -P port [-o mixed] [-O mixed] [-t iptype] [-s|+s] [-b|+b]`

| `-d` | `--device` | device | （缺省网卡） | 网卡 |
| `-E` | `--src-eth` | eth | HTML 示例 | 源 MAC；触发 VIRT |
| `-I` | `--src-ip` | ip | | 源 IP |
| `-P` | `--src-port` | port（必填） | | 监听端口 |
| `-o` | `--ip4opts` | mixed | | IPv4 options |
| `-O` | `--ip6exts` | mixed | | IPv6 扩展 |
| `-t` | `--iptype` | iptype | `ip4` | 未给 `--src-ip` 时用 |
| `-s` | `--showscreen` | bool | 关 | 数据打到屏幕 |
| `-b` | `--echoback` | bool | **开** | 回显给客户 |

## 例子

- `nz 92 --src-port 9999`
