## 行为

TCP 中继：客户连本机 `--src-port`，本机再连 `--server-ip`:`--server-port`。`--allowed-clients` 缺省 all。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 183 [-d device] [-E eth] [-I ip] -P port [-o mixed] [-O mixed] [-t iptype] -x ip -X port [-c ips]`

| `-d` | `--device` | device | （缺省网卡） | 网卡 |
| `-E` | `--src-eth` | eth | HTML 示例 | 源 MAC；触发 VIRT |
| `-I` | `--src-ip` | ip | | 源 IP |
| `-P` | `--src-port` | port（必填） | | 监听端口 |
| `-o` | `--ip4opts` | mixed | | IPv4 options |
| `-O` | `--ip6exts` | mixed | | IPv6 扩展 |
| `-t` | `--iptype` | iptype | `ip4` | 未给 `--src-ip` 时用 |
| `-x` | `--server-ip` | ip | （必填） | 后端地址；185 为列表 |
| `-X` | `--server-port` | port（必填） | | 后端端口 |
| `-c` | `--allowed-clients` | ips | `all` | 允许的客户 IP |

## 例子

- `nz 183 --src-port 8080 --server-ip 192.0.2.2 --server-port 80`
