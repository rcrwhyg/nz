## 行为

perf TCP 服务端：收 HELLO → 发 DATA → BYE → 等 BYEACK。绑定 `--src-port`。协议见 [_common.md](_common.md)。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 155 [-d device] [-E eth] [-I ip] -P port [-o mixed] [-O mixed] [-t iptype]`

| `-d` | `--device` | device | （缺省网卡） | 网卡 |
| `-E` | `--src-eth` | eth | HTML 示例 | 源 MAC；触发 VIRT |
| `-I` | `--src-ip` | ip | | 源 IP |
| `-P` | `--src-port` | port（必填） | | 监听端口 |
| `-o` | `--ip4opts` | mixed | | IPv4 options |
| `-O` | `--ip6exts` | mixed | | IPv6 扩展 |
| `-t` | `--iptype` | iptype | `ip4` | 未给 `--src-ip` 时用 |

## 例子

- `nz 155 --src-port 5001`

## 权限 / 网络

无特权。CI 假套接字 + 短 HELLO duration。
