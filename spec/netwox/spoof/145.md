## 行为

IP 路径发送 IPv6+UDP。

共用组包 / spoofip / 字段长名见 [_common.md](_common.md)。短选项以本工具 Usage 为准（字母会平移）。

## CLI

Usage：`nz 145 [-c uint32] [-l uint32] [-f uint32] [-g uint32] [-h ip] [-i ip] [-j ip6exts] [-o port] [-p port] [-q mixed_data] [-a spoofip] [-e uint32] [-s uint32] [-t uint32]`

其余长名见 [_common.md](_common.md)。测试用长名。

## 例子

- `nz 145 --ip6-dst 2001:db8::1 --udp-dst 53`（文档地址，勿对公网发）

## 权限 / 网络

需 spoof。仅本机 / 实验室 / 书面授权。CI 假通道，不发送到真网。
