# 工具 spec

- 工具号：34
- 标题：Spoof EthernetIp4 packet
- 建议名：`spoof-eth-ip4`

- 同义词：frame, hping, mac, send
- 相位：7
- 状态：draft

## 行为

链路发送 Eth+IPv4+`--ip4-data`。高级 `--eth-type`（帮助 2048）、`--ip4-ihl`/`--ip4-totlen`/`--ip4-checksum` 仅 isset 才字面写入并警告。发前打屏。

共用组包 / spoofip / 字段长名见 [_common.md](_common.md)。短选项以本工具 Usage 为准（字母会平移）。

## CLI

Usage：`nz 34 [-d device] [-a eth] [-b eth] [-c uint32] [-e uint32] [-f|+f] [-g|+g] [-h|+h] [-i uint32] [-j uint32] [-k uint32] [-l ip] [-m ip] [-n ip4opts] [-o mixed_data] [-p uint32] [-q uint32] [-r uint32] [-s uint32]`

其余长名见 [_common.md](_common.md)。测试用长名。

## 例子

- `nz 34 --ip4-dst 192.0.2.1`（文档地址，勿对公网发）

## 权限 / 网络

需 spoof。仅本机 / 实验室 / 书面授权。CI 假通道，不发送到真网。
