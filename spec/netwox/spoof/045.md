# 工具 spec

- 工具号：45
- 标题：Spoof of packet samples : fragment, ip4opt:lsrr
- 建议名：`spoof-sample-lsrr`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/45.html`
- 源：`src/netwox-src/src/tools/000045.c`
- 树节点：spoof IP；spoof UDP；spoof TCP；spoof ICMP
- 同义词：ip4 option, send
- 相位：7
- 状态：draft

## 行为

发送硬编码样本（`--sample` 1–5，缺省 1）。`--fragsize` 0=不分片。`--display` 默认关。`--spoofip` 缺省 best。Loose Source Route。

共用组包 / spoofip / 字段长名见 [_common.md](_common.md)。短选项以本工具 Usage 为准（字母会平移）。

## CLI

Usage：`nz 45 [-s ip] [-d ip] [-S port] [-D port] [-n uint32] [-f uint32] [-x|+x] [-i ips] [-a spoofip]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-s` | `--ip4-src` | ip | （参数类型默认） | 源 |
| `-d` | `--ip4-dst` | ip | （HTML 示例 `5.6.7.8`） | 目的 |
| `-S` | `--tcp-src` | port | 仅 isset；否则随机 1024–65535 | 样本源端口 |
| `-D` | `--tcp-dst` | port | 仅 isset；否则 80 | 样本目的端口（syslog 样本不用此作 UDP dst） |
| `-n` | `--sample` | uint32 | `1` | 1–5 |
| `-f` | `--fragsize` | uint32 | `0` | 0=不分片 |
| `-x` | `--display` | bool | 关 | 打印样本 |
| `-a` | `--spoofip` | spoofip（Advanced） | `best` | 发送路径 |
| `-i` | `--ip4opt-ips` | ips | `1.2.3.4,5.6.7.8` | LSRR 地址 |

## 例子

- `nz 45 --sample 2 --fragsize 8`（文档地址，勿对公网发）

## 权限 / 网络

需 spoof。仅本机 / 实验室 / 书面授权。CI 假通道，不发送到真网。
