# 工具 spec

- 工具号：33
- 标题：Spoof EthernetArp packet
- 建议名：`spoof-eth-arp`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/33.html`
- 源：`src/netwox-src/src/tools/000033.c`
- 树节点：spoof Ethernet；spoof ARP
- 同义词：frame, hping, mac, send
- 相位：7
- 状态：draft

## 行为

链路发送 Eth+ARP/RARP。`--eth-type` 默认 2054；`--arp-op` 默认 1。发前打屏。

共用组包 / spoofip / 字段长名见 [_common.md](_common.md)。短选项以本工具 Usage 为准（字母会平移）。

## CLI

Usage：`nz 33 [-d device] [-a eth] [-b eth] [-c uint32] [-e uint32] [-f eth] [-g ip] [-h eth] [-i ip]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-d` | `--device` | device | （缺省网卡） | 网卡 |
| `-a`/`-b` | `--eth-src`/`--eth-dst` | eth | initdefault | 以太网地址 |
| `-c` | `--eth-type` | uint32 | `2054` | ARP=2054，RARP=32821 |
| `-e` | `--arp-op` | uint32 | `1` | 1–4 |
| `-f` | `--arp-ethsrc` | eth | （参数默认） | ARP 发送方 MAC |
| `-g` | `--arp-ipsrc` | ip | `0.0.0.0` | ARP 发送方 IP |
| `-h` | `--arp-ethdst` | eth | `0:0:0:0:0:0` | ARP 目标 MAC |
| `-i` | `--arp-ipdst` | ip | `0.0.0.0` | ARP 目标 IP |

## 例子

- `nz 33 --arp-op 1 --arp-ipdst 192.0.2.1`（文档地址，勿对公网发）

## 权限 / 网络
