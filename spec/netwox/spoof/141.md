# 工具 spec

- 工具号：141
- 标题：Spoof EthernetIp6Udp packet
- 建议名：`spoof-eth-ip6-udp`

## 行为

链路发送 Eth+IPv6+UDP。eth-type / IPv6 地址规则同 140。

共用组包 / spoofip / 字段长名见 [_common.md](_common.md)。短选项以本工具 Usage 为准（字母会平移）。

## CLI

Usage：`nz 141 [-d device] [-a eth] [-b eth] [-c uint32] [-l uint32] [-f uint32] [-g uint32] [-h ip] [-i ip] [-j ip6exts] [-o port] [-p port] [-q mixed_data] [-r uint32] [-e uint32] [-s uint32] [-t uint32]`

其余长名见 [_common.md](_common.md)。测试用长名。

## 例子

- `nz 141 --ip6-dst 2001:db8::1 --udp-dst 53`（文档地址，勿对公网发）

## 权限 / 网络

需 spoof。仅本机 / 实验室 / 书面授权。CI 假通道，不发送到真网。
