# 工具 spec

- 工具号：41
- 标题：Spoof Ip4Icmp4 packet
- 建议名：`spoof-ip4-icmp4`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/41.html`
- 源：`src/netwox-src/src/tools/000041.c`
- 树节点：spoof IP；spoof ICMP
- 同义词：hping, send
- 相位：7
- 状态：draft

## 行为

IP 路径发送 IPv4+ICMPv4。ICMP 语义同 37。`--spoofip` 缺省 best。

共用组包 / spoofip / 字段长名见 [_common.md](_common.md)。短选项以本工具 Usage 为准（字母会平移）。

## CLI

Usage：`nz 41 [-c uint32] [-e uint32] [-f|+f] [-g|+g] [-h|+h] [-i uint32] [-j uint32] [-k uint32] [-l ip] [-m ip] [-n ip4opts] [-o uint32] [-p uint32] [-a spoofip] [-r uint32] [-s uint32] [-t uint32] [-u uint32]`

其余长名见 [_common.md](_common.md)。测试用长名。

## 例子

- `nz 41 --ip4-dst 192.0.2.1 --icmp-type 8`（文档地址，勿对公网发）

## 权限 / 网络

需 spoof。仅本机 / 实验室 / 书面授权。CI 假通道，不发送到真网。
