- 工具号：144
- 标题：Spoof Ip6 packet

## 行为

IP 路径发送 IPv6+`--ip6-data`。`--spoofip` 缺省 best。地址/扩展仅 isset。

共用组包 / spoofip / 字段长名见 [_common.md](_common.md)。短选项以本工具 Usage 为准（字母会平移）。

## CLI

Usage：`nz 144 [-c uint32] [-l uint32] [-f uint32] [-g uint32] [-h ip] [-i ip] [-j ip6exts] [-k mixed_data] [-a spoofip] [-e uint32]`

其余长名见 [_common.md](_common.md)。测试用长名。

## 例子

- `nz 144 --ip6-dst 2001:db8::1`（文档地址，勿对公网发）

## 权限 / 网络

需 spoof。仅本机 / 实验室 / 书面授权。CI 假通道，不发送到真网。
