- 工具号：38
- 标题：Spoof Ip4 packet

## 行为

IP 路径发送 IPv4+`--ip4-data`。无 `--device`。`--spoofip` Advanced，缺省 best。发前 IP array+dump。

共用组包 / spoofip / 字段长名见 [_common.md](_common.md)。短选项以本工具 Usage 为准（字母会平移）。

## CLI

Usage：`nz 38 [-c uint32] [-e uint32] [-f|+f] [-g|+g] [-h|+h] [-i uint32] [-j uint32] [-k uint32] [-l ip] [-m ip] [-n ip4opts] [-o mixed_data] [-a spoofip] [-p uint32] [-q uint32] [-r uint32]`

其余长名见 [_common.md](_common.md)。测试用长名。

## 例子

- `nz 38 --ip4-dst 192.0.2.1`（文档地址，勿对公网发）

## 权限 / 网络

需 spoof。仅本机 / 实验室 / 书面授权。CI 假通道，不发送到真网。
