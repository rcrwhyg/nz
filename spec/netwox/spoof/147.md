## 行为

IP 路径发送 IPv6+ICMPv6。ICMP 语义同 143。`--spoofip` 缺省 best。

共用组包 / spoofip / 字段长名见 [_common.md](_common.md)。短选项以本工具 Usage 为准（字母会平移）。

## CLI

Usage：`nz 147 [-c uint32] [-l uint32] [-f uint32] [-g uint32] [-h ip] [-i ip] [-j ip6exts] [-o uint32] [-p uint32] [-a spoofip] [-e uint32] [-r uint32]`

其余长名见 [_common.md](_common.md)。测试用长名。

## 例子

- `nz 147 --ip6-dst 2001:db8::1 --icmp-type 128`（文档地址，勿对公网发）

## 权限 / 网络

需 spoof。仅本机 / 实验室 / 书面授权。CI 假通道，不发送到真网。
