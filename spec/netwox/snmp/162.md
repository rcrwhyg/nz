# 工具 spec

- 工具号：162
- 标题：SNMP Trap2
- 建议名：`snmp-trap2`
- 同义词：（C 注册 `snmptrap`，与 161 同）
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/162.html`
- 源：`src/netwox-src/src/tools/000162.c`
- 树节点：client UDP SNMP
- 相位：10（SNMP 族）
- 状态：draft

## 行为

发 **SNMPv2 TRAP2**（UDP **162**）：三个 varbind — `sysUpTime.0`（`--timestamp`）、`snmpTrapOID.0`（`--enterprise`）、用户 `--oidname`/`--oidtype`/`--oidvalue`。**无**响应等待。

共用见 [_common.md](_common.md)。

## CLI

Usage：`nz 162 -i ip [-p 162] -r enterprise -z timestamp -n oidname -t type -V value [SNMP 通用…]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--dst-ip` | ip（必填） | | 接收方 |
| `-p` | `--dst-port` | port | `162` | |
| `-r` | `--enterprise` | oid（必填） | `.1.1` | snmpTrapOID 值 |
| `-z` | `--timestamp` | uint32（必填） | | sysUpTime |
| `-n` | `--oidname` | oid（必填） | `.1.2` | 第三 varbind OID |
| `-t` | `--oidtype` | oidtype（必填） | `s` | |
| `-V` | `--oidvalue` | buf（必填） | | |

## 例子

- `nz 162 --dst-ip 192.0.2.1 --timestamp 100 --oidvalue alert`
