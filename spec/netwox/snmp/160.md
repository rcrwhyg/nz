# 工具 spec

- 工具号：160
- 标题：SNMP Walk
- 建议名：`snmp-walk`

- 相位：10（SNMP 族）
- 状态：draft

## 行为

从 `--oid` 起循环 **GETNEXT**：每步打印 `oid: value` 一行，将当前 oid 更新为响应 oid；直到 walk 结束（v1：**errorstatus≠0** → `DATAEND`；v2：返回 oid **等于**当前 oid → `DATAEND`）。外层 `do/while` 直至非 `OK`。

共用见 [_common.md](_common.md)（端口 **161**）。

## CLI

Usage：`nz 160 -i ip [-p 161] -q oid [SNMP 通用…]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--dst-ip` | ip（必填） | | 代理 |
| `-p` | `--dst-port` | port | `161` | |
| `-q` | `--oid` | oid（必填） | `.0.1` | 起始 OID |

## 例子

- `nz 160 --dst-ip 192.0.2.1 --oid .1.3.6.1.2.1`
