# 工具 spec

- 工具号：164
- 标题：SNMP Set
- 建议名：`snmp-set`
- 同义词：`snmpset`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/164.html`
- 源：`src/netwox-src/src/tools/000164.c`
- 树节点：client UDP SNMP
- 相位：10（SNMP 族）
- 状态：draft

## 行为

对 `--name`/`--type`/`--value` 发 **SETREQUEST**，匹配 RESPONSE 后打印设置结果的 synth 值一行。

共用见 [_common.md](_common.md)（端口 **161**）。

## CLI

Usage：`nz 164 -i ip [-p 161] -n name -t type -V value [SNMP 通用…]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--dst-ip` | ip（必填） | | 代理 |
| `-p` | `--dst-port` | port | `161` | |
| `-n` | `--name` | oid（必填） | `.1.3.6.1.2.1.1.4.0` | OID |
| `-t` | `--type` | oidtype（必填） | `s` | 类型字母 |
| `-V` | `--value` | buf（必填） | | 新值 |

## 例子

- `nz 164 --dst-ip 192.0.2.1 --name .1.3.6.1.2.1.1.4.0 --type s --value admin@lab`

## 权限 / 网络

无特权。CI 假 SNMP。
