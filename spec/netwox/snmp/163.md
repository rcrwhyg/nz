# 工具 spec

- 工具号：163
- 标题：SNMP Inform
- 建议名：`snmp-inform`

- 树节点：client UDP SNMP
- 相位：10（SNMP 族）
- 状态：draft

## 行为

发 **INFORMREQUEST**（UDP **162**），varbind 布局同 162（sysUpTime + snmpTrapOID + 用户 oid）；等 **RESPONSE**（3 个 varbind，校验第 3 个 oid 与 `--oidname` 一致）。**不**校验其余字段。

共用见 [_common.md](_common.md)。

## CLI

Usage：`nz 163 -i ip [-p 162] -r enterprise -z timestamp -n oidname -t type -V value [SNMP 通用…]`

参数表同 [162.md](162.md)（`-r/-z/-n/-t/-V` + SNMP 通用）。

## 例子

- `nz 163 --dst-ip 192.0.2.1 --timestamp 200 --oidvalue info`

## 权限 / 网络

无特权。CI 假 SNMP 回 RESP。
