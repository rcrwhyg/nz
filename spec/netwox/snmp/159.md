# 工具 spec

- 工具号：159
- 标题：SNMP Get
- 建议名：`snmp-get`
- 同义词：`snmpget`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/159.html`
- 源：`src/netwox-src/src/tools/000159.c`
- 树节点：client UDP SNMP
- 相位：10（SNMP 族）
- 状态：draft

## 行为

对 `--oid` 发 **GETREQUEST**，匹配 RESPONSE 后打印唯一 varbind 值的 synth 文本一行。

共用见 [_common.md](_common.md)（端口 **161**）。

## CLI

Usage：`nz 159 -i ip [-p 161] -q oid [SNMP 通用…]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--dst-ip` | ip（必填） | | 代理 |
| `-p` | `--dst-port` | port | `161` | |
| `-q` | `--oid` | oid（必填） | `.1.3.6.1.2.1.1.4.0` | 查询 OID |

加 [_common.md](_common.md) 中 SNMP 通用参数。

## 例子

- `nz 159 --dst-ip 192.0.2.1 --oid .1.3.6.1.2.1.1.1.0`

## 权限 / 网络

无特权。CI 假 SNMP。
