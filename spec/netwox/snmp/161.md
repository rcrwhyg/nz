## 行为

发 **SNMPv1 TRAP**（UDP **162**）：enterprise、agent IP、traptype、specifictrap、timestamp + 一个 varbind（oidname/oidtype/oidvalue）。**无**响应处理（`pfuncrep == NULL`）。

共用见 [_common.md](_common.md)。

## CLI

Usage：`nz 161 -i ip [-p 162] -r enterprise -a agent -s traptype [-S specific] -z timestamp -n oidname -t type -V value [SNMP 通用…]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--dst-ip` | ip（必填） | | 接收方 |
| `-p` | `--dst-port` | port | `162` | |
| `-r` | `--enterprise` | oid（必填） | `.1.1` | enterprise |
| `-a` | `--agent` | ip（必填） | | agent 地址 |
| `-s` | `--traptype` | uint32（必填） | `3` | generic trap |
| `-S` | `--specifictrap` | uint32 | | specific trap |
| `-z` | `--timestamp` | uint32（必填） | | sysUpTime 类 ticks |
| `-n` | `--oidname` | oid（必填） | `.1.2` | varbind OID |
| `-t` | `--oidtype` | oidtype（必填） | `s` | 类型字母 |
| `-V` | `--oidvalue` | buf（必填） | | 值 |

## 例子

- `nz 161 --dst-ip 192.0.2.1 --agent 192.0.2.10 --timestamp 12345 --oidvalue hello`
