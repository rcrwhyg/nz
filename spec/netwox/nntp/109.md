# 工具 spec

- 工具号：109
- 标题：Download messages
- 建议名：`nntp-get`
- 源：`src/netwox-src/src/tools/000109.c`
- 树节点：client TCP NNTP
- 相位：10（NNTP 族）
- 状态：draft

## 行为

下载 `--newsgroup` 中 `--firstartnum` 到 `--lastartnum` 的文章（`lastartnum` 缺省 `4294967295` = UINT32_MAX 即到末尾）。

## CLI

Usage：`nz 109 -i ip [-p 119] -g newsgroup -n first [-N last] [-u user] [-a pass] [-T ms]`

| `-g` | `--newsgroup` | buf（必填） | |
| `-n` | `--firstartnum` | uint32（必填） | `1` |
| `-N` | `--lastartnum` | uint32 | `4294967295` |
