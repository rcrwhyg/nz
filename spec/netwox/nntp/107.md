# 工具 spec

- 工具号：107
- 标题：Post a newsgroup message
- 建议名：`nntp-post`
- 源：`src/netwox-src/src/tools/000107.c`
- 树节点：client TCP NNTP
- 相位：10（NNTP 族）
- 状态：draft

## 行为

连 NNTP，发 POST 到 `--newsgroup`。`--from`/`--subject` 必填。可选 body/att。

## CLI

Usage：`nz 107 -i ip [-p 119] -f from [-n name] -g newsgroup -S subject [-B body] [-A att] [-T ms] [-u user] [-a pass]`

| 短 | 长 | 类型 | 默认 |
|----|----|------|------|
| `-f` | `--from` | email（必填） | |
| `-g` | `--newsgroup` | buf（必填） | |
| `-S` | `--subject` | buf（必填） | `hello` |
| `-B` | `--file-body` | file | `file-body.txt` |
| `-A` | `--file-att` | file | `file-att.tgz` |
| `-T` | `--timeout` | uint32 | `60000` |
| `-u` | `--user` | login | |
| `-a` | `--pass` | password | |
