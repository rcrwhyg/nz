# 工具 spec

- 工具号：153
- 标题：IRC client listing channels
- 建议名：`irc-list`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/153.html`
- 源：`src/netwox-src/src/tools/000153.c`
- 树节点：client TCP IRC
- 相位：10（IRC 族）
- 状态：draft

## 行为

连 IRC 注册后发 LIST，打印频道列表后 QUIT。`--nickname` 必填；可选 `--password`。

## CLI

Usage：`nz 153 -i ip [-p 6667] -n nick [-w pass]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--dst-ip` | ip（必填） | | |
| `-p` | `--dst-port` | port | `6667` | |
| `-n` | `--nickname` | login（必填） | | |
| `-w` | `--password` | password | | |
