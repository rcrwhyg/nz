## 行为

交互式 IRC 客户端：NICK/USER 注册后 `io_kbd_loop`（stdin ↔ 服务器）。`--nickname`/`--username` 必填；可选 `--password`/`--realname`。**registry stdin**。

## CLI

Usage：`nz 152 -i ip [-p 6667] -n nick -u user [-w pass] [-r realname]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--dst-ip` | ip（必填） | | 服务器 |
| `-p` | `--dst-port` | port | `6667` | |
| `-n` | `--nickname` | login（必填） | | |
| `-u` | `--username` | login（必填） | | |
| `-w` | `--password` | password | | 可选 |
| `-r` | `--realname` | buf | | |
