# 工具 spec

- 工具号：154
- 标题：IRC client listening on a channel
- 建议名：`irc-listen`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/154.html`
- 源：`src/netwox-src/src/tools/000154.c`
- 树节点：client TCP IRC
- 相位：10（IRC 族）
- 状态：draft

## 行为

注册后 JOIN `--channel`，被动打印频道消息直到断开。

## CLI

Usage：`nz 154 -i ip [-p 6667] -n nick -c channel [-w pass]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--dst-ip` | ip（必填） | | |
| `-p` | `--dst-port` | port | `6667` | |
| `-n` | `--nickname` | login（必填） | | |
| `-c` | `--channel` | buf（必填） | `#chan` | |
| `-w` | `--password` | password | | |
