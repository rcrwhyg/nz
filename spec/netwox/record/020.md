- 工具号：20
- 标题：Search for strings in packets from a record
- 建议名：`record-grep`

- 相位：5
- 状态：draft

## 行为

在**整包字节**里搜模式，命中的包写入输出。`-S`/`-M`/`-R` 是 radio1，**默认 string**。`--case` 默认关（不区分大小写）。`--mixed` 先按 mixed 解码模式再搜。`--regexp` 匹配前把包内 `NUL` 换成空格。空模式（string）对照 `memmem` 空针：每包都命中。无特权。不需要 DLT。

## CLI

Usage：`nz 20 -f file -F file [-r recordencode] -p data [-c|+c] [-S|+S] [-M|+M] [-R|+R]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-f` | `--src-file` | 可读文件（必填） | （无） | 输入 |
| `-F` | `--dst-file` | 可写文件（必填） | （无） | 输出 |
| `-r` | `--recordencode` | recordencode | `bin` | 输出编码 |
| `-p` | `--pattern` | data（必填） | （无） | 模式 |
| `-c` | `--case` | bool | 关 | 区分大小写 |
| `-S` | `--string` | radio1 | **开** | 原始字节 |
| `-M` | `--mixed` | radio1 | 关 | 先 mixed 解码 |
| `-R` | `--regexp` | radio1 | 关 | 正则 |

## 例子

- `nz 20 -f in.pcap -F out.pcap -p HTTP`
- mixed：`-M -p "'hello' 09 'bob'"`
