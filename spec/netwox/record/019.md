# 工具 spec

- 工具号：19
- 标题：Extract a range of packets from a record
- 建议名：`record-slice`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/19.html`
- 源：`src/netwox-src/src/tools/000019.c`
- 树节点：record
- 同义词：capture
- 相位：5
- 状态：draft

## 行为

按包序号切片（从 **1** 起，含端点）。不解析 DLT，原样拷贝字节。`--start` 为 `0` 当作 `1`；`--end` 为 `0` 表示无上限。`start > end` 为无效范围。无特权。

## CLI

Usage：`nz 19 -f file -F file [-r recordencode] [-s uint32] [-e uint32]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-f` | `--src-file` | 可读文件（必填） | （无） | 输入 |
| `-F` | `--dst-file` | 可写文件（必填） | （无） | 输出 |
| `-r` | `--recordencode` | recordencode | `bin` | 输出编码 |
| `-s` | `--start` | uint32 | `0`（当作 1） | 起始包号 |
| `-e` | `--end` | uint32 | `0`（无上限） | 结束包号 |

## 例子

- `nz 19 -f in.pcap -F out.pcap --start 2 --end 5`

## 权限 / 网络

无。
