- 标题：Spoof a record

- 同义词：capture, frame, send
- 相位：5
- 状态：draft

## 行为

读 record，把每包发到网上。record 的 DLT 必须与 spoof 通道 DLT 相同，否则失败。DLT 不是 `raw` 时用链路 spoof（`--device`）；是 `raw` 时用 IP spoof（`--spoofip`，缺省 `best`）。`--screen` 发送前按 synth 打头、载荷不打。`--keypress` 每包先按键；工具 0 因此标 stdin。`--device` / `--spoofip` 为 Advanced。

## CLI

Usage：`nz 14 -f file [-t dlt] [-s|+s] [-k|+k] [-d device] [-i spoofip]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-f` | `--file` | 可读文件（必填） | （无） | 输入 record |
| `-t` | `--dlt` | dlt | `ether` | 文件内报文 DLT |
| `-s` | `--screen` | bool | 关 | 发送前显示 |
| `-k` | `--keypress` | bool | 关 | 每包按键 |
| `-d` | `--device` | device（Advanced） | （缺省网卡） | 非 raw 时的网卡 |
| `-i` | `--spoofip` | spoofip（Advanced） | `best` | raw 时如何发 IP |

## 例子

- `nz 14 -f capture.pcap`

## 权限 / 网络

需要 spoof。仅本机 / 实验室 / 书面授权目标。CI 用假 spoof 后端，不抓真网、不对公网。
