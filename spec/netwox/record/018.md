# 工具 spec

- 工具号：18
- 标题：Reassemble IP packets of a record, and reorder TCP flow
- 建议名：`record-reasm`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/18.html`
- 源：`src/netwox-src/src/tools/000018.c`
- 树节点：record
- 同义词：capture
- 相位：5
- 状态：draft

## 行为

读入后**默认做 IP 重组**；`--tcpreord` 再按 TCP 序号重排。原文写明可能丢包（缺片、乱序窗口外）。无特权。重组语义见 [pkt.md](../../netwib/pkt.md)。

## CLI

Usage：`nz 18 -f file [-t dlt] -F file [-r recordencode] [-o|+o]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-f` | `--src-file` | 可读文件（必填） | （无） | 输入 |
| `-t` | `--input-dlt` | dlt | `ether` | 输入 DLT |
| `-F` | `--dst-file` | 可写文件（必填） | （无） | 输出 |
| `-r` | `--recordencode` | recordencode | `bin` | 输出编码 |
| `-o` | `--tcpreord` | bool | 关 | 同时重排 TCP |

## 例子

- `nz 18 -f in.pcap -F out.pcap --tcpreord`
