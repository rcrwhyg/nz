## 行为

转换 record 格式，并可改 DLT（例如 pcap→mixed、ether↔raw）。输入/输出 DLT 不同时走库 `conv`，缺字段 **fillblank**（能算则算，否则空白）。无特权。输出 `--recordencode` 缺省 `bin`。

## CLI

Usage：`nz 16 -f file [-t dlt] -F file [-T dlt] [-r recordencode]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-f` | `--src-file` | 可读文件（必填） | （无） | 输入 |
| `-t` | `--input-dlt` | dlt | `ether` | 输入 DLT |
| `-F` | `--dst-file` | 可写文件（必填） | （无） | 输出 |
| `-T` | `--output-dlt` | dlt | `ether` | 输出 DLT |
| `-r` | `--recordencode` | recordencode | `bin` | 输出编码 |

## 例子

- `nz 16 -f in.pcap -F out.mixed --recordencode mixed_wrap`
