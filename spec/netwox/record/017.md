# 工具 spec

- 工具号：17
- 标题：Recompute checksums of packets in a record
- 建议名：`record-csum`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/17.html`
- 源：`src/netwox-src/src/tools/000017.c`
- 树节点：record
- 同义词：capture, verify
- 相位：5
- 状态：draft

## 行为

按输入 DLT 从链路层重算 IP/传输/ICMP 校验和，写入另一 record。某包算失败则**原包原样写出**（不丢包）。无特权。

## CLI

Usage：`nz 17 -f file [-t dlt] -F file [-r recordencode]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-f` | `--src-file` | 可读文件（必填） | （无） | 输入 |
| `-t` | `--input-dlt` | dlt | `ether` | 输入 DLT |
| `-F` | `--dst-file` | 可写文件（必填） | （无） | 输出 |
| `-r` | `--recordencode` | recordencode | `bin` | 输出编码 |

## 例子

- `nz 17 -f in.pcap -F out.pcap`

## 权限 / 网络

无。
