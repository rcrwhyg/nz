# 工具 spec

- 工具号：177
- 标题：Check if a SMTP server is up
- 建议名：`smtp-probe`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/177.html`
- 源：`src/netwox-src/src/tools/000177.c`
- 树节点：client TCP SMTP
- 同义词：（无）
- 相位：10（SMTP 族）
- 状态：draft

## 行为

TCP 连 `--dst-ip`:`--dst-port`（缺省 25），读首个 220 问候，发 `QUIT`，期望 221 后关闭。**不**发 MAIL/DATA。失败时按 txtproto 错误退出。

共用见 [_common.md](_common.md)（**timeout 60000**，非发信 180000）。

## CLI

Usage：`nz 177 -i ip [-p port] [-T ms]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--dst-ip` | ip（必填） | | 服务器 |
| `-p` | `--dst-port` | port | `25` | |
| `-T` | `--timeout` | uint32 | **`60000`** | ms |

## 例子

- `nz 177 --dst-ip 192.0.2.1`

## 权限 / 网络

无特权。CI 假 SMTP。
