# 工具 spec

- 工具号：106
- 标题：Send an email
- 建议名：`smtp-send`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/106.html`
- 源：`src/netwox-src/src/tools/000106.c`
- 树节点：client TCP SMTP
- 同义词：（无）
- 相位：10（SMTP 族）
- 状态：draft

## 行为

连 SMTP 服务器，构造 MIME 邮件（可选 `--file-body` / `--file-att`），经 `smtp_send` 投递。信封 `--mail-from`/`--rcpt-to` 未设时分别用 `--from`/`--to`。

共用见 [_common.md](_common.md)。

## CLI

Usage：`nz 106 -i ip [-p port] -f from [-n name] -r to -S subject [-F mail-from] [-R rcpt-to] [-B body-file] [-A att-file] [-T ms]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--dst-ip` | ip（必填） | | 服务器 |
| `-p` | `--dst-port` | port | `25` | |
| `-f` | `--from` | email（必填） | `user@example.com` | From 头 |
| `-n` | `--from-name` | buf | | 显示名 |
| `-r` | `--to` | email（必填） | `user2@example.fr` | To 头 |
| `-S` | `--subject` | buf（必填） | `hello` | |
| `-F` | `--mail-from` | email | `me@example.com` | MAIL FROM |
| `-R` | `--rcpt-to` | email | `you@example.fr` | RCPT TO |
| `-B` | `--file-body` | file | `file-body.txt` | 正文 |
| `-A` | `--file-att` | file | `file-att.tgz` | 附件 |
| `-T` | `--timeout` | uint32 | `180000` | ms |

## 例子

- `nz 106 --dst-ip 192.0.2.1 --from me@lab --to you@lab --subject test`

## 权限 / 网络
