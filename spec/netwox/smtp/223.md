# 工具 spec

- 工具号：223
- 标题：Forward an email
- 建议名：`smtp-fwd`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/223.html`
- 源：`src/netwox-src/src/tools/000223.c`
- 树节点：client TCP SMTP
- 同义词：（无）
- 相位：10（SMTP 族）
- 状态：draft

## 行为

同 106 连 SMTP 并 `smtp_send`，但 MIME 嵌入 **`--file-fwd` 必填** 的待转发邮件；可选 `--file-body` 作为转发说明正文。信封/头语义同 106。

共用见 [_common.md](_common.md)。

## CLI

Usage：`nz 223 -i ip [-p port] -f from [-n name] -r to -S subject -A file-fwd [-F mail-from] [-R rcpt-to] [-B body-file] [-T ms]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--dst-ip` | ip（必填） | | 服务器 |
| `-p` | `--dst-port` | port | `25` | |
| `-f` | `--from` | email（必填） | `user@example.com` | From 头 |
| `-n` | `--from-name` | buf | | 显示名 |
| `-r` | `--to` | email（必填） | `user2@example.fr` | To 头 |
| `-S` | `--subject` | buf（必填） | `hello` | |
| `-A` | `--file-fwd` | file（必填） | `file-fwd.eml` | 待转发邮件 |
| `-F` | `--mail-from` | email | `me@example.com` | MAIL FROM |
| `-R` | `--rcpt-to` | email | `you@example.fr` | RCPT TO |
| `-B` | `--file-body` | file | `file-body.txt` | 可选说明正文 |
| `-T` | `--timeout` | uint32 | `180000` | ms |

## 例子

- `nz 223 --dst-ip 192.0.2.1 --file-fwd saved.eml --from fwd@lab --to rcpt@lab --subject Fwd`
