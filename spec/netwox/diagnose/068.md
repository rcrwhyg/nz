## 行为

同 67 + EthIP（无 dst-eth）。

共用循环与 EthIP 必填见 [_common.md](_common.md)。

## CLI

Usage：`nz 68 -i ips -p ports [-d device] [-E eth] [-I ip] [-m uint32] [-M uint32] [-u|+u] [-n uint32]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--ips` | ips（必填） | | 目标 |
| `-p` | `--ports` | ports（必填） | | 端口 |
| `-d` | `--device` | device | 运行时必填 | 网卡 |
| `-E` | `--src-eth` | eth | 运行时必填 | 源 MAC |
| `-I` | `--src-ip` | ip | 运行时必填 | 源 IP |
| `-m` | `--min-ms` | uint32（Advanced） | `0` | 包间隔 |
| `-M` | `--max-ms` | uint32（Advanced） | `5000` | 等应答 |
| `-u` | `--disp-useful` | bool（Advanced） | 关 | 只打有用行 |
| `-n` | `--numtargets` | uint32（Advanced） | `20` | 并发 |

## 例子

- `nz 68 --ips 192.0.2.1 --ports 80 --device eth0 --src-eth 0:a:a:a:a:a --src-ip 192.0.2.8`（文档地址，勿对公网）
