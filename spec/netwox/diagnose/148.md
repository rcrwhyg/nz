## 行为

IPv6 Neighbor Solicitation → Advertisement。`--dst-ip` 为 IPv6。无 `--spoofip`。ping 标志为普通选项。

共用循环与 EthIP 必填见 [_common.md](_common.md)。

## CLI

Usage：`nz 148 -i ip [-c uint32] [-m uint32] [-b|+b] [-1|+1]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--dst-ip` | ip6（必填） | | 目的 IPv6 |
| `-c` | `--max-count` | uint32 | `4294967295` | 次数 |
| `-m` | `--max-ms` | uint32 | `1000` | 等待 |
| `-b` | `--beep` | bool | 关 | 响铃 |
| `-1` | `--display01` | bool | 关 | 只打 `0`/`1` |

## 例子

- `nz 148 --dst-ip 2001:db8::1`（文档地址，勿对公网）

## 权限 / 网络

需 sniff+spoof。仅本机 / 实验室 / 书面授权。CI 假通道，不对公网。
