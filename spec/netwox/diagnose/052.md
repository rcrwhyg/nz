# 工具 spec

- 工具号：52
- 标题：Ping TCP (EthIp spoof)
- 建议名：`ping-tcp-eth`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/52.html`
- 源：`src/netwox-src/src/tools/000052.c`
- 树节点：ping
- 同义词：（无）
- 相位：8
- 状态：draft

## 行为

同 51 + EthIP。收到 SYN+ACK 后再发 RST，避免 SYN 洪泛。

共用循环与 EthIP 必填见 [_common.md](_common.md)。

## CLI

Usage：`nz 52 -i ip [-d device] [-E eth] [-e eth] [-I ip] [-p port] [-c uint32] [-m uint32] [-b|+b] [-1|+1]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--dst-ip` | ip（必填） | | 目的 |
| `-d` | `--device` | device | 运行时必填 | 网卡 |
| `-E` | `--src-eth` | eth | 运行时必填 | 源 MAC |
| `-e` | `--dst-eth` | eth | 运行时必填 | 目的 MAC |
| `-I` | `--src-ip` | ip | 运行时必填 | 源 IP |
| `-p` | `--dst-port` | port | `80` | 目的端口 |
| `-c` | `--max-count` | uint32（Advanced） | `4294967295` | 次数 |
| `-m` | `--max-ms` | uint32（Advanced） | `1000` | 等待 |
| `-b` | `--beep` | bool（Advanced） | 关 | 响铃 |
| `-1` | `--display01` | bool（Advanced） | 关 | 只打 `0`/`1` |

## 例子

- `nz 52 --dst-ip 192.0.2.1 --device eth0 --src-eth 0:a:a:a:a:a --dst-eth 0:b:b:b:b:b --src-ip 192.0.2.8`（文档地址，勿对公网）

## 权限 / 网络

需 sniff+spoof。仅本机 / 实验室 / 书面授权。CI 假通道，不对公网。
