# 工具 spec

- 工具号：72
- 标题：Scan ARP (EthIp spoof)
- 建议名：`scan-arp-eth`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/72.html`
- 源：`src/netwox-src/src/tools/000072.c`
- 树节点：scan
- 同义词：nmap
- 相位：8
- 状态：draft

## 行为

同 71 + EthIP。**无 `--numtargets` CLI**，内部仍用默认 20。无 dst-eth。

共用循环与 EthIP 必填见 [_common.md](_common.md)。

## CLI

Usage：`nz 72 -i ips [-d device] [-E eth] [-I ip] [-m uint32] [-M uint32] [-u|+u]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--ips` | ips（必填） | | 目标 |
| `-d` | `--device` | device | 运行时必填 | 网卡 |
| `-E` | `--src-eth` | eth | 运行时必填 | 源 MAC |
| `-I` | `--src-ip` | ip | 运行时必填 | 源 IP |
| `-m` | `--min-ms` | uint32（Advanced） | `0` | 包间隔 |
| `-M` | `--max-ms` | uint32（Advanced） | `5000` | 等应答 |
| `-u` | `--disp-useful` | bool（Advanced） | 关 | 只打有用行 |

## 例子

- `nz 72 --ips 192.0.2.1 --device eth0 --src-eth 0:a:a:a:a:a --src-ip 192.0.2.8`（文档地址，勿对公网）
