# 工具 spec

- 工具号：51

- 源：`src/netwox-src/src/tools/000051.c`

- 同义词：（无）
- 相位：8
- 状态：draft

## 行为

TCP SYN。开→SYN+ACK，关→RST+ACK，二者都算 reached。`--dst-port` 默认 80。

共用循环与 EthIP 必填见 [_common.md](_common.md)。

## CLI

Usage：`nz 51 -i ip [-p port] [-s spoofip] [-c uint32] [-m uint32] [-b|+b] [-1|+1]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--dst-ip` | ip（必填） | | 目的 |
| `-p` | `--dst-port` | port | `80` | 目的端口 |
| `-s` | `--spoofip` | spoofip（Advanced） | `best` | 发送路径 |
| `-c` | `--max-count` | uint32（Advanced） | `4294967295` | 次数；`0`=无限 |
| `-m` | `--max-ms` | uint32（Advanced） | `1000` | 每次等待 |
| `-b` | `--beep` | bool（Advanced） | 关 | 通了响铃 |
| `-1` | `--display01` | bool（Advanced） | 关 | 只打 `0`/`1` |

## 例子

- `nz 51 --dst-ip 192.0.2.1 --dst-port 80`（文档地址，勿对公网）

## 权限 / 网络

需 sniff+spoof。仅本机 / 实验室 / 书面授权。CI 假通道，不对公网。
