## 行为

同 55 + EthIP。C 仍列出 `--dst-eth`，但 ARP EthIP **不要求** dst-eth isset。仍要求 device/src-eth/src-ip。

共用循环与 EthIP 必填见 [_common.md](_common.md)。

## CLI

Usage：`nz 56 -i ip [-d device] [-E eth] [-e eth] [-I ip] [-c uint32] [-m uint32] [-b|+b] [-1|+1]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--dst-ip` | ip（必填） | | 目的 |
| `-d` | `--device` | device | 运行时必填 | 网卡 |
| `-E` | `--src-eth` | eth | 运行时必填 | 源 MAC |
| `-e` | `--dst-eth` | eth | 不要求 isset | 目的 MAC |
| `-I` | `--src-ip` | ip | 运行时必填 | 源 IP |
| `-c` | `--max-count` | uint32（Advanced） | `4294967295` | 次数 |
| `-m` | `--max-ms` | uint32（Advanced） | `1000` | 等待 |
| `-b` | `--beep` | bool（Advanced） | 关 | 响铃 |
| `-1` | `--display01` | bool（Advanced） | 关 | 只打 `0`/`1` |

## 例子

- `nz 56 --dst-ip 192.0.2.1 --device eth0 --src-eth 0:a:a:a:a:a --src-ip 192.0.2.8`（文档地址，勿对公网）
