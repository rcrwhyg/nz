# 工具 spec

- 工具号：55
- 标题：Ping ARP
- 建议名：`ping-arp`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/55.html`
- 源：`src/netwox-src/src/tools/000055.c`
- 树节点：ping
- 同义词：（无）
- 相位：8
- 状态：draft

## 行为

ARP Request → Reply。无 `--spoofip`。count/ms/beep/display01 为普通选项（非 Advanced）。

共用循环与 EthIP 必填见 [_common.md](_common.md)。

## CLI

Usage：`nz 55 -i ip [-c uint32] [-m uint32] [-b|+b] [-1|+1]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--dst-ip` | ip（必填） | | 目的 |
| `-c` | `--max-count` | uint32 | `4294967295` | 次数；`0`=无限 |
| `-m` | `--max-ms` | uint32 | `1000` | 等待 |
| `-b` | `--beep` | bool | 关 | 响铃 |
| `-1` | `--display01` | bool | 关 | 只打 `0`/`1` |

## 例子

- `nz 55 --dst-ip 192.0.2.1`（文档地址，勿对公网）

## 权限 / 网络

需 sniff+spoof。仅本机 / 实验室 / 书面授权。CI 假通道，不对公网。
