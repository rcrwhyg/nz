# 工具 spec

- 工具号：71
- 标题：Scan ARP
- 建议名：`scan-arp`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/71.html`
- 源：`src/netwox-src/src/tools/000071.c`
- 树节点：scan
- 同义词：nmap
- 相位：8
- 状态：draft

## 行为

ARP 扫描。无 `--spoofip`。通了打印 `{ip} : {eth}`。

共用循环与 EthIP 必填见 [_common.md](_common.md)。

## CLI

Usage：`nz 71 -i ips [-m uint32] [-M uint32] [-u|+u] [-n uint32]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--ips` | ips（必填） | | 目标 |
| `-m` | `--min-ms` | uint32（Advanced） | `0` | 包间隔 |
| `-M` | `--max-ms` | uint32（Advanced） | `5000` | 等应答 |
| `-u` | `--disp-useful` | bool（Advanced） | 关 | 只打有用行 |
| `-n` | `--numtargets` | uint32（Advanced） | `20` | 并发 |

## 例子

- `nz 71 --ips 192.0.2.0/24`（文档地址，勿对公网）

## 权限 / 网络

需 sniff+spoof。仅本机 / 实验室 / 书面授权。CI 假通道，不对公网。
