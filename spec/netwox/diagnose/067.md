# 工具 spec

- 工具号：67
- 标题：Scan TCP
- 建议名：`scan-tcp`

- 源：`src/netwox-src/src/tools/000067.c`

- 同义词：nmap
- 相位：8
- 状态：draft

## 行为

TCP SYN 扫描。开打印 `open`；关/超时仅非 `--disp-useful` 时打印 `closed`/`timeout`。

共用循环与 EthIP 必填见 [_common.md](_common.md)。

## CLI

Usage：`nz 67 -i ips -p ports [-s spoofip] [-m uint32] [-M uint32] [-u|+u] [-n uint32]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--ips` | ips（必填） | | 目标 |
| `-p` | `--ports` | ports（必填） | | 端口 |
| `-s` | `--spoofip` | spoofip（Advanced） | `best` | 发送路径 |
| `-m` | `--min-ms` | uint32（Advanced） | `0` | 包间隔 |
| `-M` | `--max-ms` | uint32（Advanced） | `5000` | 等应答 |
| `-u` | `--disp-useful` | bool（Advanced） | 关 | 只打有用行 |
| `-n` | `--numtargets` | uint32（Advanced） | `20` | 并发；>200 钳到 200 |

## 例子

- `nz 67 --ips 192.0.2.1 --ports 80,443`（文档地址，勿对公网）

## 权限 / 网络

需 sniff+spoof。仅本机 / 实验室 / 书面授权。CI 假通道，不对公网。
