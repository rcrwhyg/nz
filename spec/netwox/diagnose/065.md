# 工具 spec

- 工具号：65
- 标题：Scan ICMP
- 建议名：`scan-icmp`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/65.html`
- 源：`src/netwox-src/src/tools/000065.c`
- 树节点：scan
- 同义词：nmap
- 相位：8
- 状态：draft

## 行为

对 `--ips` 发 Echo。有应答打印 `{ip} : reached`；超时且非 `--disp-useful` 打印 `unreached`。

共用循环与 EthIP 必填见 [_common.md](_common.md)。

## CLI

Usage：`nz 65 -i ips [-s spoofip] [-m uint32] [-M uint32] [-u|+u] [-n uint32]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--ips` | ips（必填） | | 目标列表/网段 |
| `-s` | `--spoofip` | spoofip（Advanced） | `best` | 发送路径 |
| `-m` | `--min-ms` | uint32（Advanced） | `0` | 包间隔 |
| `-M` | `--max-ms` | uint32（Advanced） | `5000` | 等应答 |
| `-u` | `--disp-useful` | bool（Advanced） | 关 | 只打有用行 |
| `-n` | `--numtargets` | uint32（Advanced） | `20` | 并发；>200 钳到 200 |

## 例子

- `nz 65 --ips 192.0.2.0/24`（文档地址，勿对公网）

## 权限 / 网络

需 sniff+spoof。仅本机 / 实验室 / 书面授权。CI 假通道，不对公网。
