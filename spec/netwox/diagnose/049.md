# 工具 spec

- 工具号：49
- 标题：Ping ICMP
- 建议名：`ping-icmp`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/49.html`
- 源：`src/netwox-src/src/tools/000049.c`
- 树节点：ping
- 同义词：（无）
- 相位：8
- 状态：draft

## 行为

ICMP Echo Request，匹配 Echo Reply。`--dst-ip` 必填。

共用循环与 EthIP 必填见 [_common.md](_common.md)。

## CLI

Usage：`nz 49 -i ip [-s spoofip] [-c uint32] [-m uint32] [-b|+b] [-1|+1]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--dst-ip` | ip（必填） | | 目的 |
| `-s` | `--spoofip` | spoofip（Advanced） | `best` | 发送路径 |
| `-c` | `--max-count` | uint32（Advanced） | `4294967295` | 次数；`0`=无限 |
| `-m` | `--max-ms` | uint32（Advanced） | `1000` | 每次等待 |
| `-b` | `--beep` | bool（Advanced） | 关 | 通了响铃 |
| `-1` | `--display01` | bool（Advanced） | 关 | 只打 `0`/`1` |

## 例子

- `nz 49 --dst-ip 192.0.2.1`（文档地址，勿对公网）

## 权限 / 网络

需 sniff+spoof。仅本机 / 实验室 / 书面授权。CI 假通道，不对公网。
