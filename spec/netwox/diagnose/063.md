- 工具号：63
- 标题：Traceroute on a specified IP protocol

- 状态：draft

## 行为

只发指定 IP 协议（`--protocol` 默认 1=ICMPv4）+ `--ip4-data` mixed。无法根据应答自动结束，必须能被中断（Ctrl-C / 工具 0 kill）。

共用循环与 EthIP 必填见 [_common.md](_common.md)。

## CLI

Usage：`nz 63 -i ip [-p uint32] [-D mixed_data] [-s spoofip] [-T uint32] [-t uint32] [-m uint32] [-r|+r]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--dst-ip` | ip（必填） | | 目的 |
| `-p` | `--protocol` | uint32 | `1` | IP 协议号 |
| `-D` | `--ip4-data` | mixed | （空） | 载荷 |
| `-s` | `--spoofip` | spoofip（Advanced） | `best` | 发送路径 |
| `-T` | `--min-ttl` | uint32（Advanced） | `1` | 起始 TTL |
| `-t` | `--max-ttl` | uint32（Advanced） | `30` | 最大 TTL |
| `-m` | `--max-ms` | uint32（Advanced） | `1000` | 等待 |
| `-r` | `--resolve` | bool（Advanced） | 关 | 反查 |

## 例子

- `nz 63 --dst-ip 192.0.2.1 --protocol 1`（文档地址，勿对公网）

## 权限 / 网络

需 sniff+spoof。仅本机 / 实验室 / 书面授权。CI 假通道，不对公网。
