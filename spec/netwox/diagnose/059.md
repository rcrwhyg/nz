# 工具 spec

- 工具号：59
- 标题：Traceroute TCP
- 建议名：`trace-tcp`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/59.html`
- 源：`src/netwox-src/src/tools/000059.c`
- 树节点：traceroute
- 同义词：tcptraceroute
- 相位：8
- 状态：draft

## 行为

TCP SYN traceroute。`--dst-port` 默认 80。

共用循环与 EthIP 必填见 [_common.md](_common.md)。

## CLI

Usage：`nz 59 -i ip [-p port] [-s spoofip] [-T uint32] [-t uint32] [-m uint32] [-r|+r]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--dst-ip` | ip（必填） | | 目的 |
| `-p` | `--dst-port` | port | `80` | 目的端口 |
| `-s` | `--spoofip` | spoofip（Advanced） | `best` | 发送路径 |
| `-T` | `--min-ttl` | uint32（Advanced） | `1` | 起始 TTL |
| `-t` | `--max-ttl` | uint32（Advanced） | `30` | 最大 TTL |
| `-m` | `--max-ms` | uint32（Advanced） | `1000` | 每跳等待 |
| `-r` | `--resolve` | bool（Advanced） | 关 | 反查主机名 |

## 例子

- `nz 59 --dst-ip 192.0.2.1 --dst-port 80`（文档地址，勿对公网）

## 权限 / 网络

需 sniff+spoof。仅本机 / 实验室 / 书面授权。CI 假通道，不对公网。
