# 工具 spec

- 工具号：64
- 标题：Traceroute on a specified IP protocol (EthIp spoof)
- 建议名：`trace-ipproto-eth`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/64.html`
- 源：`src/netwox-src/src/tools/000064.c`
- 树节点：traceroute
- 同义词：（无）
- 相位：8
- 状态：draft

## 行为

同 63 + EthIP。64 的 `--protocol` 帮助写 ip protocol（仍默认 1）。

共用循环与 EthIP 必填见 [_common.md](_common.md)。

## CLI

Usage：`nz 64 -i ip [-d device] [-E eth] [-e eth] [-I ip] [-p uint32] [-D mixed_data] [-T uint32] [-t uint32] [-m uint32] [-r|+r]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--dst-ip` | ip（必填） | | 目的 |
| `-d` | `--device` | device | 运行时必填 | 网卡 |
| `-E` | `--src-eth` | eth | 运行时必填 | 源 MAC |
| `-e` | `--dst-eth` | eth | 运行时必填 | 目的 MAC |
| `-I` | `--src-ip` | ip | 运行时必填 | 源 IP |
| `-p` | `--protocol` | uint32 | `1` | IP 协议号 |
| `-D` | `--ip4-data` | mixed | （空） | 载荷 |
| `-T` | `--min-ttl` | uint32（Advanced） | `1` | 起始 TTL |
| `-t` | `--max-ttl` | uint32（Advanced） | `30` | 最大 TTL |
| `-m` | `--max-ms` | uint32（Advanced） | `1000` | 等待 |
| `-r` | `--resolve` | bool（Advanced） | 关 | 反查 |

## 例子

- `nz 64 --dst-ip 192.0.2.1 --device eth0 --src-eth 0:a:a:a:a:a --dst-eth 0:b:b:b:b:b --src-ip 192.0.2.8`（文档地址，勿对公网）
