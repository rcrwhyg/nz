## 行为

同 59 + EthIP。

共用循环与 EthIP 必填见 [_common.md](_common.md)。

## CLI

Usage：`nz 60 -i ip [-d device] [-E eth] [-e eth] [-I ip] [-p port] [-T uint32] [-t uint32] [-m uint32] [-r|+r]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--dst-ip` | ip（必填） | | 目的 |
| `-d` | `--device` | device | 运行时必填 | 网卡 |
| `-E` | `--src-eth` | eth | 运行时必填 | 源 MAC |
| `-e` | `--dst-eth` | eth | 运行时必填 | 目的 MAC |
| `-I` | `--src-ip` | ip | 运行时必填 | 源 IP |
| `-p` | `--dst-port` | port | `80` | 目的端口 |
| `-T` | `--min-ttl` | uint32（Advanced） | `1` | 起始 TTL |
| `-t` | `--max-ttl` | uint32（Advanced） | `30` | 最大 TTL |
| `-m` | `--max-ms` | uint32（Advanced） | `1000` | 每跳等待 |
| `-r` | `--resolve` | bool（Advanced） | 关 | 反查主机名 |

## 例子

- `nz 60 --dst-ip 192.0.2.1 --device eth0 --src-eth 0:a:a:a:a:a --dst-eth 0:b:b:b:b:b --src-ip 192.0.2.8`（文档地址，勿对公网）
