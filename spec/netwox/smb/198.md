# 工具 spec

- 标题：SMB/CIFS client: list shares
- 建议名：`smb-shares`
- 同义词：`smbclient`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/198.html`
- 源：`src/netwox-src/src/tools/000198.c`
- 树节点：client TCP SMB
- 相位：10（SMB 族）

## 行为

IPC 模式连服务器（**无** `--share`），列共享：每行块 `share=…` / `comment=…` / `sharetype=…`。

共用见 [_common.md](_common.md) IPC 段。

## CLI

Usage：`nz 198 -i ip [-p 139] [IPC 通用…]`

无 `--share`。其余同 IPC 通用参数。

## 例子

- `nz 198 --dst-ip 192.0.2.1`

## 权限 / 网络

无特权。CI 假 SMB。
