# 工具 spec

- 工具号：206
- 标题：SMB/CIFS client: put a file
- 建议名：`smb-put`
- 同义词：`smbclient`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/206.html`
- 源：`src/netwox-src/src/tools/000206.c`
- 树节点：client TCP SMB
- 相位：10（SMB 族）
- 状态：draft

## 行为

上传 `--localfilename` 到远端 `--remotefilename`。

共用见 [_common.md](_common.md)。

## CLI

Usage：`nz 206 -i ip -s share -f local -F remote [share 通用…]`

| `-f` | `--localfilename` | file_rd（必填） | | 本地 |
| `-F` | `--remotefilename` | file（必填） | | 远端 |

## 例子

- `nz 206 --dst-ip 192.0.2.1 --share public --localfilename data.bin --remotefilename upload/data.bin`

## 权限 / 网络

无特权。CI 假 SMB。
