# 工具 spec

- 工具号：208
- 标题：SMB/CIFS client: recursively put a directory
- 建议名：`smb-put-dir`
- 同义词：`smbclient`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/208.html`
- 源：`src/netwox-src/src/tools/000208.c`
- 树节点：client TCP SMB
- 相位：10（SMB 族）
- 状态：draft

## 行为

递归上传 `--localdirname` 到 `--remotedirname`（`dirrec_put`）。

共用见 [_common.md](_common.md)。

## CLI

Usage：`nz 208 -i ip -s share -f local -F remote [share 通用…]`

| `-f` | `--localdirname` | dir_rd（必填） | | 本地目录 |
| `-F` | `--remotedirname` | dir（必填） | | 远端目录 |

## 例子

- `nz 208 --dst-ip 192.0.2.1 --share public --localdirname ./out --remotedirname /backup`

## 权限 / 网络

无特权。CI 假 SMB。
