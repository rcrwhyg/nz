# 工具 spec

- 工具号：203
- 标题：SMB/CIFS client: delete a file
- 建议名：`smb-rm`
- 同义词：`smbclient`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/203.html`
- 源：`src/netwox-src/src/tools/000203.c`
- 树节点：client TCP SMB
- 相位：10（SMB 族）
- 状态：draft

## 行为

删除远端 `--filename`。

共用见 [_common.md](_common.md)。

## CLI

Usage：`nz 203 -i ip -s share -f filename [share 通用…]`

| `-f` | `--filename` | file（必填） | | 远端文件 |

## 例子

- `nz 203 --dst-ip 192.0.2.1 --share public --filename todo.txt`

## 权限 / 网络

无特权。CI 假 SMB。
