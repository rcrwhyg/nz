# 工具 spec

- 工具号：199
- 标题：SMB/CIFS client: create a directory
- 建议名：`smb-mkdir`
- 同义词：`smbclient`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/199.html`
- 源：`src/netwox-src/src/tools/000199.c`
- 树节点：client TCP SMB
- 相位：10（SMB 族）
- 状态：draft

## 行为

在 `--share` 上创建远端 `--dirname`。

共用见 [_common.md](_common.md)。

## CLI

Usage：`nz 199 -i ip -s share -f dirname [share 通用…]`

| `-f` | `--dirname` | dir（必填） | | 远端目录 |

加 share 通用参数。

## 例子

- `nz 199 --dst-ip 192.0.2.1 --share public --dirname newdir`

## 权限 / 网络

无特权。CI 假 SMB。
