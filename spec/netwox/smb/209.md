# 工具 spec

- 工具号：209
- 标题：SMB/CIFS client: recursively delete a directory
- 建议名：`smb-rm-dir`
- 同义词：`smbclient`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/209.html`
- 源：`src/netwox-src/src/tools/000209.c`
- 树节点：client TCP SMB
- 相位：10（SMB 族）
- 状态：draft

## 行为

递归删除 `--dirname` 及其内容（`dirrec_del`）。仅授权实验室。

共用见 [_common.md](_common.md)。

## CLI

Usage：`nz 209 -i ip -s share -f dirname [share 通用…]`

| `-f` | `--dirname` | dir（必填） | | 远端目录 |

## 例子

- `nz 209 --dst-ip 192.0.2.1 --share public --dirname /tmp/tree`

## 权限 / 网络

无特权。CI 假 SMB。
