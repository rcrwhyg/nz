# 工具 spec

- 工具号：207
- 标题：SMB/CIFS client: recursively get a directory
- 建议名：`smb-get-dir`
- 同义词：`smbclient`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/207.html`
- 源：`src/netwox-src/src/tools/000207.c`
- 树节点：client TCP SMB
- 相位：10（SMB 族）
- 状态：draft

## 行为

递归下载 `--remotedirname` 到 `--localdirname`（`dirrec_get`）。

共用见 [_common.md](_common.md)。

## CLI

Usage：`nz 207 -i ip -s share -F remote -f local [share 通用…]`

| `-F` | `--remotedirname` | dir（必填） | | 远端目录 |
| `-f` | `--localdirname` | dir_wr（必填） | | 本地目录 |

## 例子

- `nz 207 --dst-ip 192.0.2.1 --share public --remotedirname /pub --localdirname ./pub`

## 权限 / 网络

无特权。CI 假 SMB。
