# 工具 spec

- 工具号：205
- 标题：SMB/CIFS client: get a file
- 建议名：`smb-get`
- 同义词：`smbclient`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/205.html`
- 源：`src/netwox-src/src/tools/000205.c`
- 树节点：client TCP SMB
- 相位：10（SMB 族）
- 状态：draft

## 行为

从远端 `--remotefilename` 下载到 `--localfilename`。

共用见 [_common.md](_common.md)。

## CLI

Usage：`nz 205 -i ip -s share -F remote -f local [share 通用…]`

| `-F` | `--remotefilename` | file（必填） | | 远端 |
| `-f` | `--localfilename` | file_wr（必填） | | 本地 |

## 例子

- `nz 205 --dst-ip 192.0.2.1 --share public --remotefilename readme.txt --localfilename readme.txt`

## 权限 / 网络

无特权。CI 假 SMB。
