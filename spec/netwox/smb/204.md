# 工具 spec

- 工具号：204
- 标题：SMB/CIFS client: rename a file
- 建议名：`smb-mv`
- 同义词：`smbclient`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/204.html`
- 源：`src/netwox-src/src/tools/000204.c`
- 树节点：client TCP SMB
- 相位：10（SMB 族）
- 状态：draft

## 行为

将 `--oldfilename` 重命名为 `--newfilename`。

共用见 [_common.md](_common.md)。

## CLI

Usage：`nz 204 -i ip -s share -f old -F new [share 通用…]`

| `-f` | `--oldfilename` | file（必填） | | 旧名 |
| `-F` | `--newfilename` | file（必填） | | 新名 |

## 例子

- `nz 204 --dst-ip 192.0.2.1 --share public --oldfilename a.txt --newfilename b.txt`

## 权限 / 网络

无特权。CI 假 SMB。
