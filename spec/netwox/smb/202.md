# 工具 spec

- 工具号：202
- 标题：SMB/CIFS client: list contents of a directory
- 建议名：`smb-ls`
- 同义词：`smbclient`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/202.html`
- 源：`src/netwox-src/src/tools/000202.c`
- 树节点：client TCP SMB
- 相位：10（SMB 族）
- 状态：draft

## 行为

列 `--dirname`：每行 `pathname (file of size N)` 或 `pathname (dir)`。

共用见 [_common.md](_common.md)。

## CLI

Usage：`nz 202 -i ip -s share -f dirname [share 通用…]`

| `-f` | `--dirname` | dir（必填） | | 远端目录 |

## 例子

- `nz 202 --dst-ip 192.0.2.1 --share public --dirname /`

## 权限 / 网络

无特权。CI 假 SMB。
