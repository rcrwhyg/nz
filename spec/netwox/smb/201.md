# 工具 spec

- 工具号：201
- 标题：SMB/CIFS client: rename a directory
- 建议名：`smb-mv-dir`
- 同义词：`smbclient`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/201.html`
- 源：`src/netwox-src/src/tools/000201.c`
- 树节点：client TCP SMB
- 相位：10（SMB 族）
- 状态：draft

## 行为

将 `--olddirname` 重命名为 `--newdirname`。

共用见 [_common.md](_common.md)。

## CLI

Usage：`nz 201 -i ip -s share -f old -F new [share 通用…]`

| `-f` | `--olddirname` | dir（必填） | | 旧名 |
| `-F` | `--newdirname` | dir（必填） | | 新名 |

## 例子

- `nz 201 --dst-ip 192.0.2.1 --share public --olddirname a --newdirname b`

## 权限 / 网络

无特权。CI 假 SMB。
