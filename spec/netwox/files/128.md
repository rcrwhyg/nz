# 工具 spec

- 工具号：128
- 标题：Split a file in smaller chunks
- 建议名：`file-split`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/128.html`
- 源：`src/netwox-src/src/tools/000128.c`
- 树节点：not-network file
- 同义词：piece
- 相位：4
- 状态：draft

## 行为

按块切文件。默认块大小 **1400000** 字节。输出 `file.1`、`file.2`、…（从 **1** 起，不是 0）。HTML 描述写过 `file.0`，以 C 为准；工具 129 的参数说明也是「不含 `.1/.2`」。**若块文件已存在则失败**，不覆盖。空输入仍会创建空的 `file.1`。

## CLI

Usage：`nz 128 -f file [-s uint32]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-f` | `--file` | 可读文件（必填） | （无） | 输入（块名的基名） |
| `-s` | `--chunk-size` | uint32 | `1400000` | 每块最大字节 |

## 例子

- `nz 128 -f big.bin -s 10` → `big.bin.1`、`big.bin.2`、…
