# 工具 spec

- 工具号：25
- 标题：Test if a directory is secure
- 建议名：`dir-secure`

- 源：`src/netwox-src/src/tools/000025.c`
- 树节点：not-network；not-network file
- 同义词：symlink, verify
- 相位：4
- 状态：draft

## 行为

Unix：目录对所有人可写则不安全（symlink 攻击面），打印 `0` 或 `1`（`%{bool:0}`）。Windows：不需要此检查，视为安全（`1`）或跳过并说明。不存在的路径失败。

## CLI

Usage：`nz 25 -d dir`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-d` | `--dir` | 可读目录（必填） | （无） | 待测目录 |

## 例子

- `nz 25 -d /tmp`（文档；CI 用临时目录）

## 权限 / 网络

无。测本地临时目录。
