# 工具 spec

- 工具号：127
- 标题：Cypher/decypher a file using a xor
- 建议名：`file-xor`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/127.html`
- 源：`src/netwox-src/src/tools/000127.c`、`modules/crypto/xor.c`
- 树节点：not-network file
- 同义词：xor
- 相位：4
- 状态：draft

## 行为

口令经 MD5 链式派生至少 **1024** 字节密钥再**字节反转**；对文件逐字节 XOR，且密钥槽随偏移变异（对照 `xor.c`，不是固定循环异或）。同一口令再跑一次即还原。先写临时文件，成功再改名为 `-o`。

**不是安全加密**：原文写明可知明文攻击。标题保留原拼写；正文只称 XOR。

## CLI

Usage：`nz 127 -p password -i file -o file`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-p` | `--password` | password（必填） | （无） | 口令 |
| `-i` | `--src-file` | 可读文件（必填） | （无） | 输入 |
| `-o` | `--dst-file` | 可写文件（必填） | （无） | 输出 |

## 例子

- `nz 127 -p secret -i a.bin -o a.xor` 再同样口令跑回
