# 工具 spec

- 工具号：29
- 标题：Convert a readable and editable file to a binary file
- 建议名：`mixed-to-bin`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/29.html`
- 源：`src/netwox-src/src/tools/000029.c`
- 树节点：not-network file
- 同义词：hexedit
- 相位：4
- 状态：draft

## 行为

工具 28 的逆：按 record 读法识别 dump/mixed 等文本，写出二进制。`28` 再 `29` 须 roundtrip。

## CLI

Usage：`nz 29 -i file -o file`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--src-file` | 可读文件（必填） | （无） | 文本 |
| `-o` | `--dst-file` | 可写文件（必填） | （无） | 二进制 |

## 例子

- `nz 29 -i a.txt -o a.bin`

## 权限 / 网络
