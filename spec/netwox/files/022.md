# 工具 spec

- 工具号：22
- 标题：Convert a string
- 建议名：`conv-str`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/22.html`
- 源：`src/netwox-src/src/tools/000022.c`
- 树节点：not-network
- 同义词：base64, hexadecimal, text, mixed, md5sum
- 相位：4
- 状态：draft

## 行为

把输入按 radio1 解码为字节：`--string`（默认）/ `--hexa` / `--mixed` / `--base64`。再按显示开关打印 string、hexa、mixed、base64 与各哈希。哈希只算不能反解。

仅当 `--title` 与四种编码显示**都关**时才看哈希：若哈希也全关，则标题 + 四种编码 + 全部哈希全开；若已开任一哈希，则不自动开编码。仅 `--title`、无编码/哈希：什么都不打。

`--data` 必填（C 短选项 `-d`，长名按类型为 `data`）。

## CLI

Usage：`nz 22 -d data [-s|+s] [-h|+h] [-m|+m] [-b|+b] [-t|+t] [-S|+S] [-H|+H] [-M|+M] [-B|+B] [-2|+2] …`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-d` | `--data` | data（必填） | 示例 `hello` | 输入 |
| `-s` | `--string` | radio1 | **开** | 输入为原文 |
| `-h` | `--hexa` | radio1 | 关 | hexa |
| `-m` | `--mixed` | radio1 | 关 | mixed |
| `-b` | `--base64` | radio1 | 关 | base64 |
| `-t` | `--title` | bool | 关* | 标题 |
| `-S` | `--disp-string` | bool | 关* | 打 string |
| `-H` | `--disp-hexa` | bool | 关* | 打 hexa |
| `-M` | `--disp-mixed` | bool | 关* | 打 mixed |
| `-B` | `--disp-base64` | bool | 关* | 打 base64 |
| `-2` | `--disp-md2` | bool | 关* | md2 |
| `-4` | `--disp-md4` | bool | 关* | md4 |
| `-5` | `--disp-md5` | bool | 关* | md5 |
| `-C` | `--disp-ripemd128` | bool | 关* | ripemd128 |
| `-D` | `--disp-ripemd160` | bool | 关* | ripemd160 |
| `-E` | `--disp-sha1` | bool | 关* | sha1 |
| `-F` | `--disp-sha224` | bool | 关* | sha224 |
| `-G` | `--disp-sha256` | bool | 关* | sha256 |
| `-J` | `--disp-sha384` | bool | 关* | sha384 |
| `-K` | `--disp-sha512` | bool | 关* | sha512 |

\* 编码类全关且哈希全关才全开。
