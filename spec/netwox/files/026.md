# 工具 spec

- 工具号：26
- 标题：Dump a file
- 建议名：`file-dump`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/26.html`
- 源：`src/netwox-src/src/tools/000026.c`
- 树节点：not-network file
- 同义词：hexadecimal, printable
- 相位：4
- 状态：draft

## 行为

按 encode 打印文件。默认 `dump`：左十六进制、右不可打印改点。其它取值见工具 12。

## CLI

Usage：`nz 26 -f file [-e encode]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-f` | `--src-file` | 可读文件（必填） | （无） | 输入 |
| `-e` | `--encode` | encode | `dump` | 编码 |

## 例子

- `nz 26 -f t.bin --encode dump`

## 权限 / 网络

无。
