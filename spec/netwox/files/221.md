# 工具 spec

- 工具号：221
- 标题：Convert a base64 encoded file to a binary file
- 建议名：`file-b64-dec`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/221.html`
- 源：`src/netwox-src/src/tools/000221.c`
- 树节点：not-network file
- 相位：4
- 状态：draft

## 行为

工具 220 的逆：按行读，去掉行首尾空白，再 `base64` 解码写出二进制。与 220 roundtrip。非法 base64 失败。

## CLI

Usage：`nz 221 -i file -o file`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--src-file` | 可读文件（必填） | （无） | 文本 |
| `-o` | `--dst-file` | 可写文件（必填） | （无） | 二进制 |

## 例子

- `nz 221 -i a.b64 -o a.bin`

## 权限 / 网络
