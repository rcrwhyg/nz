# 工具 spec

- 工具号：31
- 标题：Convert a file from dos to unix
- 建议名：`dos2unix`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/31.html`
- 源：`src/netwox-src/src/tools/000031.c`
- 树节点：not-network file
- 同义词：dos2unix
- 相位：4
- 状态：draft

## 行为

按行读入，每行写出时补 `0x0A`。写临时文件再改名为 `-o`。与工具 30 成对：Unix 文本 `30` 再 `31` 应回到 Unix 行尾（末行会带换行）。

## CLI

Usage：`nz 31 -i file -o file`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--src-file` | 可读文件（必填） | （无） | 输入 |
| `-o` | `--dst-file` | 可写文件（必填） | （无） | 输出 |

## 例子

- `nz 31 -i dos.txt -o unix.txt`
