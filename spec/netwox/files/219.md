# 工具 spec

- 工具号：219
- 标题：Compute cryptographic hash of a file (md5, sha, etc.)
- 建议名：`file-hash`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/219.html`
- 源：`src/netwox-src/src/tools/000219.c`
- 树节点：not-network file
- 同义词：md5sum
- 相位：4
- 状态：draft

## 行为

对文件计算与工具 22 同一组哈希。C 描述有笔误（M5、SHA-356）；本 spec 用正确名：md2/md4/md5、ripemd128/160、sha1/224/256/384/512。

自动全开规则：**仅当 `--title` 关且没有任何哈希开关开**时，才把 title 与全部哈希打开。只开 `-t`、无哈希开关：不自动开哈希，**什么都不打**。

## CLI

Usage：`nz 219 -f file [-t|+t] [-2|+2] …`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-f` | `--src-file` | 可读文件（必填） | （无） | 输入 |
| `-t` | `--title` | bool | 关* | 标题 |
| `-2` | `--disp-md2` | bool | 关* | md2 |
| `-4` | `--disp-md4` | bool | 关* | md4 |
| `-5` | `--disp-md5` | bool | 关* | md5 |
| `-C` | `--disp-ripemd128` | bool | 关* | ripemd128 |
| `-D` | `--disp-ripemd160` | bool | 关* | ripemd160 |
| `-E` | `--disp-sha1` | bool | 关* | sha1 |
| `-F` | `--disp-sha224` | bool | 关* | sha224 |
| `-G` | `--disp-sha256` | bool | 关* | sha256 |
| `-J` | `--disp-sha384` | bool | 关* | sha384 |
| `-K` | `--disp-sha512` | bool | 关* | sha512 |

\* title 关且哈希全关则全开。

## 例子

- `nz 219 -f empty`：全部算法（带标题）
- `nz 219 -f empty --disp-md5`：一行 MD5，无标题
