## 行为

默认英语词图：从对照词表随机取 `--numimages`（默认 5）个词，口令为各词**前两个字母**拼接，并给出两套 variation（替换 1 个 / 2 个字符，字符来自 `--allowedcharvar`）。`--pronounceable` 改按音节拼；`--maxsyllables` 默认 `0`（对照 HTML 示例为 0；实现闸对照 `passwordgene`：0 表示不限制）。语言 radio1：英语默认 / 法语 / 西班牙语。

词表与元音/辅音表对照 `000191.c`，实现可内嵌同等列表，**不要把大数组贴进 spec**。测试注入 RNG，不依赖真随机。

## CLI

Usage：`nz 191 [-n uint32] [-i uint32] [-E|+E] [-F|+F] [-S|+S] [-p|+p] [-m uint32] [-a data]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-n` | `--numpassword` | uint32 | `1` | 生成条数 |
| `-i` | `--numimages` | uint32 | `5` | 词图个数 |
| `-E` | `--lang-english` | radio1 | **开** | 英语 |
| `-F` | `--lang-french` | radio1 | 关 | 法语 |
| `-S` | `--lang-spanish` | radio1 | 关 | 西班牙语 |
| `-p` | `--pronounceable` | bool | 关 | 可发音 |
| `-m` | `--maxsyllables` | uint32 | `0` | 可发音最大音节 |
| `-a` | `--allowedcharvar` | data | `ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789@|!()[]{}/$+&^*` | variation 字符 |

## 例子

- `nz 191 --numimages 5 --lang-english`：口令长度 10，并打 images / variation
- `nz 191 --pronounceable --maxsyllables 3`
