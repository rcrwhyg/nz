# 工具 spec

- 工具号：220
- 标题：Convert a binary file to a base64 encoded file
- 建议名：`file-b64-enc`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/220.html`
- 源：`src/netwox-src/src/tools/000220.c`
- 树节点：not-network file
- 相位：4
- 状态：draft

## 行为

二进制 → base64 文本。C 用 `base64_wrap`，按 **54 字节**输入块换行（54/3×4 = 72 列）。文本写出。与工具 221 互逆。

## CLI

Usage：`nz 220 -i file -o file`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--src-file` | 可读文件（必填） | （无） | 二进制 |
| `-o` | `--dst-file` | 可写文件（必填） | （无） | 文本 |

## 例子

- `nz 220 -i a.bin -o a.b64`

## 权限 / 网络

无。
