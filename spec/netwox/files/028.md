# 工具 spec

- 工具号：28
- 标题：Convert a binary file to readable and editable file
- 建议名：`bin-to-mixed`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/28.html`
- 源：`src/netwox-src/src/tools/000028.c`
- 树节点：not-network file
- 同义词：hexedit
- 相位：4
- 状态：draft

## 行为

把二进制写成可编辑文本。HTML 写 mixed；**C 实际用 encode=`dump`**（左 hex、右点，每块后换行，文本写出），以 C 为准。建议名仍叫 `bin-to-mixed`（历史名）。与工具 29 互逆。

## CLI

Usage：`nz 28 -i file -o file`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--src-file` | 可读文件（必填） | （无） | 二进制 |
| `-o` | `--dst-file` | 可写文件（必填） | （无） | 文本 |

长名缺省按类型：`src-file` / `dst-file`。

## 例子

- `nz 28 -i a.bin -o a.txt`

## 权限 / 网络
