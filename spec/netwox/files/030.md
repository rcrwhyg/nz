# 工具 spec

- 工具号：30
- 标题：Convert a file from unix to dos
- 建议名：`unix2dos`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/30.html`
- 源：`src/netwox-src/src/tools/000030.c`
- 树节点：not-network file
- 同义词：unix2dos
- 相位：4
- 状态：draft

## 行为

按行读入（识别 LF / CRLF / CR），每行写出时补 `0x0D 0x0A`。写临时文件再改名为 `-o`。输入输出是两个路径，不是原地 `-f`。文档写明只适合文本；C 用 line IO，不额外因 `NUL` 失败。无换行的最后一行仍补行尾。

## CLI

Usage：`nz 30 -i file -o file`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--src-file` | 可读文件（必填） | （无） | 输入 |
| `-o` | `--dst-file` | 可写文件（必填） | （无） | 输出 |

## 例子

- `nz 30 -i unix.txt -o dos.txt`

## 权限 / 网络
