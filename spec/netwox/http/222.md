# 工具 spec

- 工具号：222
- 标题：In a HTML file, suppress links pointing to local urls
- 建议名：`html-unlink-local`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/222.html`
- 源：`src/netwox-src/src/tools/000222.c`
- 树节点：not-network
- 同义词：（无）
- 相位：10（HTTP 族）
- 状态：draft

## 行为

去掉 local/unknown scheme 链接，保留 http/https/ftp 等远端 href。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 222 -i src -o dst`

| `-i` | `--src-file` | file_rd（必填） | `t.htm` | 输入 |
| `-o` | `--dst-file` | file_wr（必填） | `out.htm` | 输出 |

## 例子

- `nz 222 --src-file in.htm --dst-file out.htm`

## 权限 / 网络

无网络。
