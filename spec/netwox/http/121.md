- 工具号：121
- 标题：HTTP PUT
- 建议名：`http-put`

- 源：`src/netwox-src/src/tools/000121.c`

- 同义词：upload, web
- 相位：10（HTTP 族）

## 行为

HTTP PUT；`--file-body` **必填**读本地文件上传；无 body display。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 121 -u uri -B file [-p ip] [-P port] [-l login] [-L password] [-U useragent] [-s|+s] [-h|+h] [-H file] [-T ms]`

| `-B` | `--file-body` | file_rd（必填） | `filebody.txt` | 上传文件 |
| `-u` | `--uri` | uri（必填） | | 目标 |
| `-p` | `--proxy-ip` | ip | | isset 启用 proxy |
| `-P` | `--proxy-port` | port | `3128` | proxy 端口 |
| `-l` | `--proxy-login` | login | | |
| `-L` | `--proxy-password` | password | | |
| `-U` | `--user-agent` | useragent | | isset 才发头 |
| `-s` | `--display-status` | bool | 关 | status 行 |
| `-h` | `--display-headers` | bool | 关 | headers→screen |
| `-H` | `--file-headers` | file_wr | `filehdr.txt` | 写 headers |
| `-T` | `--timeout` | uint32 | `60000` | ms |

## 例子

- `nz 121 --uri http://192.0.2.1/upload --file-body payload.bin`
