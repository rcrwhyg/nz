# 工具 spec

- 工具号：182
- 标题：Obtain size of a web file (http://... or ftp://...)
- 建议名：`web-size`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/182.html`
- 源：`src/netwox-src/src/tools/000182.c`
- 树节点：client TCP FTP / client TCP HTTP
- 同义词：curl, wget
- 相位：10（HTTP 族）
- 状态：draft

## 行为

不下载正文，只打印 size（uint32 一行）；目录等不可 size 则失败。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 182 -u uri [-p ip] [-P port] [-l login] [-L password] [-U useragent] [-f|+f] [-T ms]`

| `-u` | `--uri` | uri（必填） | `http://www.example.com/` | |
| `-p` | `--proxy-ip` | ip | | |
| `-P` | `--proxy-port` | port | `3128` | |
| `-l` | `--proxy-login` | login | | |
| `-L` | `--proxy-password` | password | | |
| `-U` | `--user-agent` | useragent | | |
| `-f` | `--ftp-passive` | bool | 关 | |
| `-T` | `--timeout` | uint32 | `60000` | ms |

## 例子

- `nz 182 --uri http://192.0.2.1/big.bin`
