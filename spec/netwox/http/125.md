## 行为

静态文件 HTTP 多客户服；目录列表 HTML；可选 basic auth 与 `--allowed-clients`。`--rootdir` 缺省 `.`。非 remadm 126。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 125 [-d device] [-E eth] [-I ip] -P port [-r rootdir] [-l login] [-L password] [-T ms] [-c ips]`

| `-P` | `--src-port` | port | `80` | 监听 |
| `-r` | `--rootdir` | dir_rd | `.` | 静态根 |
| `-l` | `--login` | login | | basic auth |
| `-L` | `--password` | password | | |
| `-T` | `--timeout` | uint32 | `60000` | ms |
| `-c` | `--allowed-clients` | ips | `all` | 允许客户 |

## 例子

- `nz 125 --src-port 8080 --rootdir ./www`

## 权限 / 网络

绑定 80 可能需特权。CI 假 mulser。
