# 工具 spec

- 工具号：210
- 标题：Web spider on command line (stay in same directory)
- 建议名：`spider-dir`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/210.html`
- 源：`src/netwox-src/src/tools/000210.c`
- 树节点：client TCP HTTP spider
- 同义词：curl, wget
- 相位：10（HTTP 族）
- 状态：draft

## 行为

同 139 参数；只抓起始 URL **同目录** 下资源（210 ACL reject 站外）。registry **backspace**。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 210 -u url [-r rootdir] [-v|+v]`

| `-u` | `--url` | uri（必填） | | 起点 |
| `-r` | `--rootdir` | dir_rd | `./spider` | 本地根 |
| `-v` | `--verbose` | bool | 关 | |

## 例子

- `nz 210 --url http://192.0.2.1/dir/page.html`
