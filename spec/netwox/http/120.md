## 行为

HTTP POST；`--parameters` 作 application/x-www-form-urlencoded 体（shell 中 `&` 需转义）。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 120 -u uri [-a parameters] [-p ip] [-P port] [-l login] [-L password] [-U useragent] [-s|+s] [-h|+h] [-H file] [-b|+b] [-B file] [-T ms]`

| `-a` | `--parameters` | buf | | POST 体参数 |
| `-u` | `--uri` | uri（必填） | | 目标 |
| `-p` | `--proxy-ip` | ip | | isset 启用 proxy |
| `-P` | `--proxy-port` | port | `3128` | proxy 端口 |
| `-l` | `--proxy-login` | login | | |
| `-L` | `--proxy-password` | password | | |
| `-U` | `--user-agent` | useragent | | isset 才发头 |
| `-s` | `--display-status` | bool | 关 | status 行 |
| `-h` | `--display-headers` | bool | 关 | headers→screen |
| `-H` | `--file-headers` | file_wr | `filehdr.txt` | 写 headers |
| `-b` | `--display-body` | bool | 关 | body→screen |
| `-B` | `--file-body` | file_wr | `filebody.txt` | 写 body |
| `-T` | `--timeout` | uint32 | `60000` | ms |

## 例子

- `nz 120 --uri http://192.0.2.1/form --parameters "k=v"`
