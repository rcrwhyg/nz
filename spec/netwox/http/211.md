# 工具 spec

- 工具号：211
- 标题：Web spider : converts a local downloaded filename to its original url
- 建议名：`spider-file-to-url`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/211.html`
- 源：`src/netwox-src/src/tools/000211.c`
- 树节点：client TCP HTTP spider
- 同义词：（无）
- 相位：10（HTTP 族）
- 状态：draft

## 行为

用 spider 配置把本地镜像路径映射回原 URL 并打印。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 211 -c conffile -f filename`

| `-c` | `--conffile` | file_rd（必填） | | spider 配置 |
| `-f` | `--filename` | file（必填） | | 本地路径 |

## 例子

- `nz 211 --conffile spider.conf --filename files/02/f.html`

## 权限 / 网络

无网络（读配置+映射）。
