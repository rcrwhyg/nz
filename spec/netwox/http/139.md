## 行为

从 `--url` 全递归镜像；`--rootdir` 缺省 `./spider`；`--verbose` 关=log SCALE。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 139 -u url [-r rootdir] [-v|+v]`

| `-u` | `--url` | uri（必填） | | 起点 |
| `-r` | `--rootdir` | dir_rd | `./spider` | 本地根 |
| `-v` | `--verbose` | bool | 关 | 详细日志 |

## 例子

- `nz 139 --url http://192.0.2.1/site/`

## 权限 / 网络
