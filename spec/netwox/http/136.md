# 工具 spec

- 工具号：136
- 标题：Web download (http://... or ftp://...)
- 建议名：`web-get`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/136.html`
- 源：`src/netwox-src/src/tools/000136.c`
- 树节点：client TCP FTP / client TCP HTTP
- 同义词：curl, wget
- 相位：10（HTTP 族）
- 状态：draft

## 行为

下载 http:// 或 ftp:// 到 `--dst-file`；可选 `--display-status`。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 136 -u uri -f file [-p ip] [-P port] [-l login] [-L password] [-U useragent] [-F|+F] [-T ms] [-s|+s]`

| `-u` | `--uri` | uri（必填） | `http://www.example.com/` | |
| `-f` | `--dst-file` | file_wr（必填） | | 落盘 |
| `-p` | `--proxy-ip` | ip | | |
| `-P` | `--proxy-port` | port | `3128` | |
| `-l` | `--proxy-login` | login | | |
| `-L` | `--proxy-password` | password | | |
| `-U` | `--user-agent` | useragent | | |
| `-F` | `--ftp-passive` | bool | 关 | FTP passive |
| `-T` | `--timeout` | uint32 | `60000` | ms |
| `-s` | `--display-status` | bool | 关 | |

## 例子

- `nz 136 --uri http://192.0.2.1/file --dst-file out.bin`

## 权限 / 网络

无特权。CI 假下载。
