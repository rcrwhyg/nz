# 工具 spec

- 工具号：175
- 标题：Web download (http://... or ftp://...) and check its MD5
- 建议名：`web-get-md5`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/175.html`
- 源：`src/netwox-src/src/tools/000175.c`
- 树节点：client TCP FTP / client TCP HTTP
- 同义词：（无）
- 相位：10（HTTP 族）
- 状态：draft

## 行为

下载到临时文件并比 `--md5`；不匹配打印两行 MD5 并 `BADVALUE`；无 `--dst-file`。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 175 -u uri -m md5 [-p ip] [-P port] [-l login] [-L password] [-U useragent] [-f|+f] [-T ms]`

| `-u` | `--uri` | uri（必填） | `http://www.example.com/` | |
| `-m` | `--md5` | md5（必填） | | 期望摘要 |
| `-p` | `--proxy-ip` | ip | | |
| `-P` | `--proxy-port` | port | `3128` | |
| `-l` | `--proxy-login` | login | | |
| `-L` | `--proxy-password` | password | | |
| `-U` | `--user-agent` | useragent | | |
| `-f` | `--ftp-passive` | bool | 关 | FTP passive |
| `-T` | `--timeout` | uint32 | `60000` | ms |

## 例子

- `nz 175 --uri http://192.0.2.1/f --md5 d41d8cd98f00b204e9800998ecf8427e`
