# 工具 spec

- 工具号：135
- 标题：Convert urls/uris in a HTML file to absolute urls
- 建议名：`html-abs`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/135.html`
- 源：`src/netwox-src/src/tools/000135.c`
- 树节点：not-network
- 同义词：（无）
- 相位：10（HTTP 族）
- 状态：draft

## 行为

相对链接转绝对 URL 写新文件。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 135 -i src -o dst -u url`

| `-i` | `--src-file` | file_rd（必填） | `t.htm` | 输入 HTML |
| `-o` | `--dst-file` | file_wr（必填） | `out.htm` | 输出 |
| `-u` | `--url` | uri（必填） | `http://s/t.htm` | 页面绝对 URL |

## 例子

- `nz 135 --src-file index.html --dst-file index2.html --url http://example.com/R/`

## 权限 / 网络

无网络。
