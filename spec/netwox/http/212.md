# 工具 spec

- 工具号：212
- 标题：Web spider : converts an url to its local downloaded filename
- 建议名：`spider-url-to-file`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/212.html`
- 源：`src/netwox-src/src/tools/000212.c`
- 树节点：client TCP HTTP spider
- 同义词：（无）
- 相位：10（HTTP 族）
- 状态：draft

## 行为

用 spider 配置把 URL 映射为本地镜像路径并打印。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 212 -c conffile -u url`

| `-c` | `--conffile` | file_rd（必填） | | spider 配置 |
| `-u` | `--url` | uri（必填） | | 原 URL |

## 例子

- `nz 212 --conffile spider.conf --url http://s/f.php`
