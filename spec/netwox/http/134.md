# 工具 spec

- 工具号：134
- 标题：Obtain urls/uris in a HTML file
- 建议名：`html-urls`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/134.html`
- 源：`src/netwox-src/src/tools/000134.c`
- 树节点：client TCP HTTP / not-network
- 同义词：（无）
- 相位：10（HTTP 族）
- 状态：draft

## 行为

读 HTML 提取 URL；`--display-http/https/ftp/none/unknown` 任一 isset 则只打对应类；**全关则全打**。

共用字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 134 -f filename [-h|+h] [-s|+s] [-t|+t] [-n|+n] [-u|+u]`

| `-f` | `--filename` | file_rd（必填） | `file.html` | HTML |
| `-h` | `--display-http` | bool | 关 | http:// |
| `-s` | `--display-https` | bool | 关 | https:// |
| `-t` | `--display-ftp` | bool | 关 | ftp:// |
| `-n` | `--display-none` | bool | 关 | 本地 |
| `-u` | `--display-unknown` | bool | 关 | unknown |

## 例子

- `nz 134 --filename page.html`
