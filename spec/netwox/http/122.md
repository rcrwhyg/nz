## CLI

Usage：`nz 122 -u uri [-p ip] [-P port] [-l login] [-L password] [-U useragent] [-s|+s] [-h|+h] [-H file] [-T ms]`

| `-u` | `--uri` | uri（必填） | | 目标 |
| `-p` | `--proxy-ip` | ip | | isset 启用 proxy |
| `-P` | `--proxy-port` | port | `3128` | proxy 端口 |
| `-l` | `--proxy-login` | login | | |
| `-L` | `--proxy-password` | password | | |
| `-U` | `--user-agent` | useragent | | isset 才发头 |
| `-s` | `--display-status` | bool | 关 | status 行 |
| `-h` | `--display-headers` | bool | 关 | headers→screen |
| `-H` | `--file-headers` | file_wr | `filehdr.txt` | 写 headers |
| `-T` | `--timeout` | uint32 | `60000` | ms |
