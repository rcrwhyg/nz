## 行为

交互式 TELNET 客户端（`io_kbd_loop`）：键盘 → 网络、网络 → 屏幕。可选 `--line-by-line`（缺省字符模式）。**registry stdin**（工具 0）。

共用见 [_common.md](_common.md)。

## CLI

Usage：`nz 99 -i ip [-p 23] [-L|+L]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--dst-ip` | ip（必填） | | 服务器 |
| `-p` | `--dst-port` | port | `23` | |
| `-L` | `--line-by-line` | bool | 关 | 行模式 |

## 例子

- `nz 99 --dst-ip 192.0.2.1`

## 权限 / 网络

无特权。CI 假 telnet 通道。
