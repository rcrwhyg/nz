# 工具 spec

- 工具号：100
- 标题：TELNET client executing one or several commands
- 建议名：`telnet-exec`
- 同义词：`rsh`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/100.html`
- 源：`src/netwox-src/src/tools/000100.c`
- 树节点：client TCP TELNET
- 相位：10（TELNET 族）
- 状态：draft

## 行为

连 TELNET 服务器，用 `--login`/`--password` 登录，依次执行尾部命令列表（`cmd1 cmd2 …`），打印每条输出后 logout。negotiate character 模式。

共用见 [_common.md](_common.md)。

## CLI

Usage：`nz 100 -i ip [-p 23] -l login -w password [-T ms] cmd1 [cmd2 …]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-i` | `--dst-ip` | ip（必填） | | 服务器 |
| `-p` | `--dst-port` | port | `23` | |
| `-l` | `--login` | login（必填） | | |
| `-w` | `--password` | password（必填） | | |
| `-T` | `--timeout` | uint32 | `60000` | ms |
| | 尾部 | more | | 命令列表 |

## 例子

- `nz 100 --dst-ip 192.0.2.1 --login root --password pass -- whoami ls`

## 权限 / 网络

无特权。CI 假 telnet。
