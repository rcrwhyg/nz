## 行为

TCP mulser 23；可选 login/password；`--line-by-line` 缺省关；`--allowed-clients` 缺省 all；会话超时 **180000 ms**。

共用见 [_common.md](_common.md)。

## CLI

Usage：`nz 170 [-P 23] [-l login] [-w pass] [-T ms] [-c ips] [-L|+L]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-P` | `--src-port` | port | `23` | 监听 |
| `-l` | `--login` | login | | 可选 |
| `-w` | `--password` | password | | |
| `-T` | `--timeout` | uint32 | `180000` | ms |
| `-c` | `--allowed-clients` | ips | `all` | |
| `-L` | `--line-by-line` | bool | 关 | |

## 例子

- `nz 170 --src-port 2323`（实验室高位口）

## 权限 / 网络
