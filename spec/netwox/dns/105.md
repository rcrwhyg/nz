# 工具 spec

- 工具号：105
- 标题：Sniff and send DNS answers
- 建议名：`dns-answer`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/105.html`
- 源：`src/netwox-src/src/tools/000105.c`
- 树节点：server UDP DNS
- 同义词：bind
- 相位：10（DNS 族）
- 状态：draft

## 行为

嗅探 UDP/53 DNS 请求，伪造固定应答（可把流量拐向指定 IP）。filter = `(用户 filter) and udp and port 53`。仅处理 IP/UDP 且 src 或 dst 为 53 的包。应答经 IP/UDP 头 swap 后 spoof 发出。`dnspktex_answer(..., ignoreunimplemented=true)`：不支持的 opcode/class/type 静默跳过。

A 不用 `--hostname`；PTR 不用 `--hostnameip`（见 _common）。

## CLI

Usage：`nz 105 -h hostname -H ip -a hostname -A ip [-T uint32] [-d device] [-f filter] [-s spoofip]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-h` | `--hostname` | hostname（必填） | `www.example.com` | 见 _common |
| `-H` | `--hostnameip` | ip（必填） | `1.2.3.4` | A 记录 IP |
| `-a` | `--authns` | hostname（必填） | `ns.example.com` | 权威 NS |
| `-A` | `--authnsip` | ip（必填） | `1.2.3.5` | NS A 附加 |
| `-T` | `--ttl` | uint32 | `10` | TTL（秒） |
| `-d` | `--device` | device | （缺省网卡） | 嗅探网卡 |
| `-f` | `--filter` | filter | | BPF；与 53 自动 AND |
| `-s` | `--spoofip` | spoofip | `best` | 发送路径 |

## 例子

- `nz 105 --hostnameip 192.0.2.10 --authns ns.lab.test --authnsip 192.0.2.11 --device eth0`（书面授权实验室）

## 权限 / 网络

需 sniff+spoof。禁止对未授权网络注入。CI 假 sniff/spoof 通道。
