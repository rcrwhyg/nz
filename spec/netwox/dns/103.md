# 工具 spec

- 工具号：103
- 标题：Obtain version of a Bind DNS server
- 建议名：`dns-bind-version`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/103.html`
- 源：`src/netwox-src/src/tools/000103.c`
- 树节点：client UDP DNS / client TCP DNS
- 同义词：（无）
- 相位：10（DNS 族）
- 状态：draft

## 行为

向 Bind 查版本：固定 question `version.bind.`、type TXT、class CH。应答 rcode OK 时取第一条 ANSWER TXT 打印一行；非 OK 或无 TXT 则不输出（对照 C）。不校验 question name 是否匹配（只比 DNS ID）。

共用 `--dst-ip`、`--tcp`、`--timeout` 见 [_common.md](_common.md)。

## CLI

Usage：`nz 103 [-d device] [-E eth] [-e eth] [-I ip] -i ip [-P port] -p port [-o mixed] [-O mixed] [-C|+C] [-T uint32]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| （sock） | 见 transport | | | `--dst-port` 缺省 53 |
| `-C` | `--tcp` | bool | 关 | TCP 而非 UDP |
| `-T` | `--timeout` | uint32 | `60000` | 超时（ms） |

## 例子

- `nz 103 --dst-ip 192.0.2.1`

## 权限 / 网络
