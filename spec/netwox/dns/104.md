# 工具 spec

- 工具号：104
- 标题：DNS server always answering same values
- 建议名：`dns-fixed`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/104.html`
- 源：`src/netwox-src/src/tools/000104.c`
- 树节点：server UDP DNS
- 同义词：bind
- 相位：10（DNS 族）
- 状态：draft

## 行为

UDP 多客户 DNS 服务；对每个 IN class QUERY 用固定 hostname/IP/authns 构造应答（A/NS/PTR/MX；其余 NOTIMP）。收发包均 array+dump。`dnspktex_answer(..., ignoreunimplemented=false)`。

共用固定应答字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 104 [-d device] [-E eth] [-I ip] -P port [-o mixed] [-O mixed] [-t iptype] -h hostname -H ip -a hostname -A ip [-T uint32]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| `-P` | `--src-port` | port | `53` | 监听口 |
| `-h` | `--hostname` | hostname（必填） | `www.example.com` | 见 _common |
| `-H` | `--hostnameip` | ip（必填） | `1.2.3.4` | A 记录 IP |
| `-a` | `--authns` | hostname（必填） | `ns.example.com` | 权威 NS |
| `-A` | `--authnsip` | ip（必填） | `1.2.3.5` | NS A 附加 |
| `-T` | `--ttl` | uint32 | `10` | TTL（秒） |

## 例子

- `nz 104 --hostname www.lab.test --hostnameip 192.0.2.10 --authns ns.lab.test --authnsip 192.0.2.11`（本机实验室）

## 权限 / 网络

绑定 53 可能需特权。仅本机 / 实验室。CI 假 UDP 多客户 IO。
