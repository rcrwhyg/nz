# 工具 spec

- 工具号：102
- 标题：Query a DNS server
- 建议名：`dns-query`
- HTML：`netw-ib-ox-ag-5.39.0/src/netwox-doc_html/tools/102.html`
- 源：`src/netwox-src/src/tools/000102.c`
- 树节点：client UDP DNS / client TCP DNS
- 同义词：dig, nslookup
- 相位：10（DNS 族）
- 状态：draft

## 行为

向 `--dst-ip` 发 DNS question；发前与收后 array+dump 显示。`--type` 支持 a、ptr、ns、mx 等（字符串解析）。PTR 且 `--name` 为 IP 字面量时自动转 in-addr.arpa / ip6.int。服务器须对该 query 权威或（`--recurdesired` 开时）允许递归。

共用客户字段见 [_common.md](_common.md)。

## CLI

Usage：`nz 102 [-d device] [-E eth] [-e eth] [-I ip] -i ip [-P port] -p port [-o mixed] [-O mixed] -n hostname -y type [-c class] [-u|+u] [-C|+C] [-T uint32]`

| 短 | 长 | 类型 | 默认 | 含义 |
|----|----|------|------|------|
| （sock） | 见 transport | | | `--dst-port` 缺省 53 |
| `-n` | `--name` | hostname（必填） | | 查询名 |
| `-y` | `--type` | buf | `a` | RR type |
| `-c` | `--class` | buf | `in` | RR class |
| `-u` | `--recurdesired` | bool | 关 | RD 位 |
| `-C` | `--tcp` | bool | 关 | TCP 而非 UDP |
| `-T` | `--timeout` | uint32 | `60000` | 超时（ms） |

## 例子

- `nz 102 --dst-ip 192.0.2.1 --name www.example.com --type a`
- `nz 102 --dst-ip 192.0.2.1 --name 192.0.2.1 --type ptr`

## 权限 / 网络

无特权（REAL）。VIRT 需 sniff+spoof。勿对公网未授权 resolver 探测。CI 假套接字。
